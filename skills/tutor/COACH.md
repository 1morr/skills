# 批改、解答、帶著做

tutor 的分支：材料交付之後，讀者回到這門課的對話時照這份。練習頁和模擬卷怎麼做在 PRACTICE.md。

會不會只看能不能把題目做出來：不出前測、不問「讀懂了嗎」。

## 開頭先讀學習紀錄

每次照這份做事，動手之前先讀學習紀錄和筆記，把「做過有錯」的題型列給讀者。他要複習，就各出一題沒看過的（或指練習頁上還沒做的那一題）；再做他這次要的事。

## 批改

- 讀者貼來畫布圖，或模擬卷寫好的紙的照片：用圖上的題目代號在答案檔找到那題，逐小題對，照老師評分會看的點（步驟、結論句）指出錯在哪一步。手寫看不清楚就問。
- 讀者貼來填答結果（一題一行字，含每題看了幾個提示、自評分數和沒拿到的給分點）：不用逐題講評，說哪幾個題型要再練。

批改完更新學習紀錄上這幾個題型的狀態，錯的每一處在筆記記一條「錯過」。

完成條件：這次碰到的每個題型，學習紀錄上的狀態和日期都更新了；每一處錯都有一條「錯過」；考前速查重組過。

## 讀者問問題

讀者說「卡在 §15」、貼一句看不懂的話，或問某一步為什麼：他是讀過導讀頁那一段還不懂才來問的。

1. 看不出卡在哪，先問一句：是哪一句、哪一步。
2. 換一種講法：更小的數字、畫一張圖、舉一個不成立的例子。一次講一步，數字用導讀頁那一段的例子。
3. 講完問一題，要他給出一個數字或一個名稱。答錯就再換一種講法。
4. 讓他懂的那個講法，在筆記記一條「懂了」；再指一題同類的練習題讓他自己做。
5. 導讀頁那一段沒教到、或講得讓人誤會的，改導讀頁的原始檔，用它旁邊的 `build.sh` 重組：下次讀到這裡就不會卡在同一個地方。

完成條件：讀者答對了那一題；筆記多了一條「懂了」，考前速查重組過；導讀頁那一段改了，或你說明了它本來就有講。

## 學習紀錄

`學習紀錄.md` 放在這門課的資料夾（沒有就放導讀頁旁邊），做材料和批改都寫它：

| 節 | 內容 | 什麼時候寫 |
| --- | --- | --- |
| 題型 | 每份導讀頁題型表的每一列一行：題型代號（`data-type`）、導讀頁的檔名和 §、狀態、最近一次做的日期 | 做材料時加列，狀態「還沒做」；批改時更新 |
| 作業進度 | 每份作業是還沒發佈、還沒交、已交，老師答案出了沒；導讀頁、練習頁、模擬卷的檔名 | 做材料時 |
| 練習題來源 | 課本章末題、In-class Exercise、過去的測驗，哪幾題出過、出在哪一頁 | 做材料時 |
| 考試形式 | 測驗怎麼考、考場發什麼，和出處（老師的公告、過去的考卷、讀者說的） | 做材料時；讀者說了就記 |
| 術語譯名 | 每個術語第一次定下的譯名，之後都用同一個 | 做材料時 |

狀態看這個題型最近一次沒看過的完整題目，只有三種：

- 還沒做。
- 做對：沒看逐步詳解，填答格全對，給分點全拿到。
- 做過有錯：其餘都是。重做同一題才對，狀態不變。

模擬卷的結果一樣記進來。紀錄是舊格式時（狀態寫「會做」「做對一次」「要提示」「不會」，或有複習日、「錯在哪一步」的欄），這次更新就改過來：會做、做對一次算做對，要提示、不會算做過有錯；「錯在哪一步」的內容搬進筆記的「錯過」；複習日的欄和開頭講 learn 模式的那一句拿掉。

## 筆記

`筆記.md` 放在學習紀錄旁邊，是讀者自己的東西：他錯過什麼、哪個講法讓他懂了。照導讀頁和題型分節：

```markdown
## topic5-guide.html

### seasonal-index
- 錯過（11/16 練習 1）：四個比率全部平均 → 先劃掉最高 0.86、最低 0.78，剩下的再平均
- 懂了：medial mean 像評審給分，去掉最高分和最低分
```

- `##` 寫導讀頁的檔名，`###` 寫題型代號（題型表的 `data-type`）。檔案裡其他標題底下的東西是讀者自己寫的，原樣留著。
- 一條記一件事，用讀者當時的數字和他自己的話：「錯過」寫錯成什麼 → 對的是什麼；「懂了」寫讓他懂的那個講法。
- 只記發生過的事：批改出來的錯、他問過的問題。課件的重點在速查卡上，筆記留給他自己的東西。

## 考前速查

`review.html` 放在導讀頁旁邊：每份導讀頁的速查卡照課程的順序排成一頁，題型下面接筆記。速查卡來自考點清單，所以重點不會漏；筆記是讀者自己的話，所以好記。筆記多了一條，或多了一份導讀頁，就重組：

```bash
python <S>/review.py topic1-guide.html topic2-guide.html --notes 筆記.md --title "<課名> 考前速查" -o review.html
```

它印「提醒」時照訊息改筆記（多半是題型代號寫錯）。讀者說要考前複習時，給他這一頁的完整路徑，再把「做過有錯」的題型列給他。

## 帶著做

只在兩種情況逐步帶：讀者說「帶我做」，或同一個題型連續兩次批改都是「做過有錯」。帶的是導讀頁上那個題型的例題，帶完讓他回練習頁做一題同類的。

- 一次只問一步（例如「df₁ 是多少？從 ANOVA 表哪裡看？」），問完就停，等讀者回答。
- 問題要讀者給出一個數字、一個步驟或一句理由，花在考試會扣分的地方：*n*、df 怎麼數，查哪張表哪一格，拿什麼跟什麼比，結論句怎麼寫。
- 數字由讀者自己從材料上讀：叫他看導讀頁的哪張圖、哪張輸出表。考試時他要自己讀。
- 答對：簡短確認，說一句為什麼對。答錯：先給提示（指到哪張圖、講義哪個 §），第二次再錯才講答案和原因。
- 卡在前置知識（例如不會算 Σ、不會查表）：就在這一步補那一點，補完回到題目。
- 讀者說「不懂」「直接告訴我」時就講解，不再追問。
- 最後請讀者寫出答案紙那一段，再對照老師的格式改。

完成條件：讀者寫出了答案紙那一段；你指了一題同類的練習題給他。
