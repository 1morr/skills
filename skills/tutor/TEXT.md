# 文科課程（`data-problems="text"`）

tutor 的分支：歷史、哲學、通識這類課，題目要的是要點和句子，不是數字。其餘照 GUIDE.md。

題目欄一樣先放題型表（看到什麼題目 → 答題要點、老師評分看什麼 → 示範題），每題的骨架改成：

1. **為什麼**：這題在問什麼、老師評分看什麼（名詞、年代、因果、立場），把課件講這一點的那一塊截過來。
2. **題目**：截題目，附翻譯圖。
3. `<details class="answer">` 裡：答題要點（列點，每點寫出處頁碼）、`.sheet` 答案紙上寫這樣（照老師範本或評分標準的句型）、常見錯誤（寫錯的年代、混淆的名詞）、這題記住。
4. 要背的東西（年代、名詞、誰主張什麼）放 `details.check` 自測，一題一個。

練習頁和模擬卷照 PRACTICE.md，換成文科的內容：

- 基本功的填答格問一個要背的東西：年代、人名、名詞、誰主張什麼。`data-answer` 列出可接受的寫法（中英文、全名和簡稱）。
- 完整題目是簡答和申論。範本答案的 `.sheet` 照老師範本或評分標準的結構寫（論點、證據、反方、結論）；給分點一點寫一個老師會給分的東西：一個論點、一個年代、一條因果、一段引用的出處，寫到讀者能對照自己的答案勾或不勾。
- 題目要讀史料、地圖、圖表的題型，題型表那一列寫 `data-reads="figure"`，題目附那份材料的截圖。
- 沒有數字就不用 `gen.py` 和 `values.json`；答案檔照舊，每題寫老師評分會看的點。

不用「數字從哪來」表和 `.calc`；GUIDE.md 的其他規則一樣。
