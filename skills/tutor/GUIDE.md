# 導讀頁與答案紙

tutor 做材料的分支：照這份寫導讀頁和答案紙。腳本位在同目錄的 `scripts/`。「§N」是導讀頁上的段落編號，由 `scripts/build.py` 依 `<h2>`、`<h3>` 的順序產生。

## 這一頁要做到什麼

左邊是你寫給這個讀者的講解，右邊的課件欄跟著講解走：他讀到哪，右邊就是老師的那一頁，按「看中文」就在課件圖下方展開 HTML 譯文對照層。

怎麼分段、先講什麼、照哪條認知路線走，依 `plan.md` 的逆向先備知識鏈與這個讀者來定——**教學順序跟著概念依賴走，不必被投影片頁碼綁成逐頁流水帳**。固定的只有這幾件：

- **實質課件頁都有落點，純過場頁標 `skip`**：有教學內容的課件頁，正文都有地方指著它（〈課件欄〉），深淺跟著考點份量走；純封面、目錄、行政公告、無實質內容的過場頁，在 `slides.json` 標記 `"skip": true`（或在 `<body>` 寫 `data-skip`），不為湊 `idle=0` 硬寫廢話。
- **老師的每一題都解**：例題、In-class Exercise、作業、過去的測驗。題目在課件欄，左邊是做法和答案，答案寫成老師的答題格式。題目在課本上的，把題目原文寫進正文。
- **「譯名（原文）」只在錨點處帶原文，同節後續保持流暢**：課件上的術語、專有名詞、制度、事件，在**① 每節（`§`）第一次出現、② 標題、③ `<dfn>` 與 `.def` 定義框、④ 速查卡與題型表、⑤ 考卷／答案紙句型**寫成「譯名（原文）」（例如「自相關函數（Autocorrelation Function, ACF）」「南進（Nam tiến）」）。**同一節後續再出現時，直接寫譯名或課件通用縮寫**（如「自相關」「ACF」「南進」），不要第二次、第十次重複塞括號原文打斷母語閱讀。表格窄格、點選題選項、放不下譯名的標題可只寫原文；一般詞（國名、世紀、常見城市）照讀者語言寫。

### 零基礎認知鷹架（三階漸進撤除）

這一頁寫給沒上過課的人。把「看懂」變成「考場獨立做得出來」，核心考點採用**三階漸進鷹架（Worked → Completion → Full）**：

1. **完整示範（Worked Example）**：新概念先拿一個最小具體例子算一次或推一次，再給正式名稱、`<dfn>` 與公式；用老師的第一題例題攤開完整步驟（`.calc` 或結構化推導），寫明每一步「看到題目哪個字才這樣做」。
2. **挖空關鍵步自測（Completion Check，`details.check`）**：緊接著給一個半完成情境，把前半框架鋪好，只挖掉最容易卡住或選錯的那一步（例如「自由度 `df` 代多少？」「這段史料支持哪一派？」「迴圈終止條件是 `<` 還是 `<=`？」），讓讀者先動腦填補再點開對照，打破「看全解覺得自己懂了」的流暢性錯覺。
3. **獨立摺疊題（Full Problem，`details.answer`）**：同題型的第二題例題或課堂練習，前面用 `<ul class="uses">` 點出用到的 `§N`，把完整做法與 `.sheet` 答案摺進 `<details class="answer">`，讓讀者白紙做完再展開核對。

非核心背景概念講清楚即可，不必每小節機械塞滿三階。詞語或符號在正式定義前就要用到時，原地給半句白話說明。

### 依學科題型選講法（去單一統計課模板）

不同學科的考點結構不同，照這門課的題型選工具，不硬套其他科目的框：

- **量化計算與圖表判讀**（統計、財管、經濟、理工）：先交代符號與單位，用 `.calc` 排「公式 → 代入 → `.ans` 結果」；需要讀程式或統計軟體輸出時放 `<pre class="output">`，查表題用 `scripts/crop.py --box/--mark` 框出對應行列；兩個長得像的公式用並排 `.defs` 或對照表標出切換條件（Seeing X vs Y）。
- **文史社科申論與比較論證**（歷史、法政、社會、個案分析）：不硬塞算式框；用比較表（`<table>`）並排拆解「學派／制度／事件 × 成因背景 × 核心機制 × 關鍵史料／條文證據 × 歷史影響或限制」；示範申論答題時在 `.sheet` 呈現「核心論點（Thesis）→ 具體證據 → 反方或邊界回應」的段落骨架，配 `.quiz` 訓練史料／概念快速配對。
- **程式實作與演算法推演**（CS、資料科學、工程）：用極小輸入畫狀態追蹤表（trace table）一步步走過變數與指標變化，明確列出迴圈不變量（invariant）、邊界條件（空集合、單一元素、重複值、溢位）與時間／空間複雜度來源；終端機與測試輸出放 `<pre class="output">`，常見實作陷阱（off-by-one、淺拷貝、型別轉換）放 `.trap`。

## 課件欄

找完材料就先把讀者要對照的每份檔案切成單頁原圖並抽出文字塊（[SKILL.md](SKILL.md)〈找材料〉第 9 步），在原始檔的資料夾跑：

```bash
uv run --no-project --with pymupdf --with pillow python <tutor目錄>/scripts/deck.py slides \
  L20=<Lecture 20 的 pdf> L21=<Lecture 21 的 pdf> HW3=<作業 3 的 pdf>
```

代號用讀者認得的短名（`L20`、`T6-Summary`、`Eg`、`HW3`）。`deck.py` 跑一次就會寫出每一頁的單套原圖、`slides/slides.json` 和待譯的 `slides/zh.json`；`zh.json` 填好後，`scripts/build.py` 會在右欄每張課件圖下方自動渲染可切換／摺疊的 `.deck-zh` HTML 譯文對照層（不塗改原圖像素，單檔體積減半，公式與文字混排也不必留空）。

導讀頁這樣接上課件與標記過場頁：

```html
<body data-slides="slides/slides.json" data-skip="L20 p.1; L20 p.30">
<h2 data-slide="L20 p.25-28">Reid 把亞洲民族主義分成哪四型？</h2>
<p data-slide="L20 p.28">三個國家各是哪一型……</p>
<tr data-slide="L20 p.29" data-key><td>前身表</td><td>旗子是殖民者；沒有旗子的泰國沒被殖民</td></tr>
```

- `data-slide` 寫在**開始講那一頁的元素**上（標題、段落、表格的一列）。那個元素的開頭捲到畫面上面三分之一時，課件欄停在那一頁、把它框起來，直到下一個 `data-slide`。
- 一段講連續幾頁寫範圍（`L20 p.3-8`）：整個範圍都框起來，課件欄停在第一頁。範圍裡某一頁要在講到它時出現，就在講它的那個元素上再寫那一頁。
- 下一個 `data-slide` 的頁就在旁邊（隔兩頁以內）時，課件欄照捲動距離平滑移過去；隔得遠就等捲到了才一次跳過去。為了先補前置知識而調整講解順序時，放心照認知順序排；只在順口回頭提別處一頁時寫文字「L22 p.7」，不必加 `data-slide` 把課件欄拉過去。
- **略過無考點過場頁（`skip`）**：封面、議程、下週預告、行政公告等完全無教學內容的頁，在 `slides.json` 該頁加 `"skip": true`，或在 `<body>` 寫 `data-skip="L20 p.1; L20 p.30"`（也可在單一元素寫 `data-slide="L20 p.1" data-skip`），`build.py` 就不會把它算進「沒講到」。有實質背景脈絡但不考的頁，仍用範圍合成一兩句交代老師放這幾頁的用意。
- `data-key` 標出必記的頁：圖本身就是考場線索的頁（地圖、關鍵圖表、老師特別圈出的那一張），寫在只指單一頁的元素上，講清楚看到這張圖要認出什麼。讀者按「只看重點」時會保留這個元素與旁邊的課件。
- 寫了 `data-slide` 的元素後面會自動出現頁碼標籤，正文直接講內容，不用寫「p.17 是……」。課件只給一半的地方（白色字、上課填空）在正文補齊並註明課件原圖留白。

**正文裡另外放局部截圖**只在讀者要盯著某一小塊細節看的時候：查表的那一格、報表上的某個數字、圖上的某條線。用 `scripts/crop.py` 截局部（`--clip`），配 `--box` 紅框、`--mark` 淡黃標色，截完開啟圖檔確認框線對準；放進 `<figure>`，`<figcaption>` 寫出處檔名與頁碼（圖內外文需要對照時，在旁邊放 `<div class="tr">` 或在圖說交代）。

## 元件

樣式備好了這些，用得到才用；沒列到的直接寫普通的 HTML（表格、清單、`<pre>` 程式碼／示意圖、`<pre class="output">` 輸出都有樣式）。框的名字由樣式加上，內文從內容寫起。

| 寫法 | 是什麼 | 適合什麼 |
| --- | --- | --- |
| `<div class="summary">` | 黃底的重點框，名字預設「重點」，`data-label="這題記住"` 可換 | 這一段讀完要帶走的那一兩句 |
| `<dfn>譯名（原文）</dfn>` | 藍色螢光筆的名詞；頁尾自動產生名詞表，照原文排 | 考試會考的術語第一次定義 |
| `<div class="def">` | 上下兩條線的定義框。裡面可加有名字的格子（`<p class="…">`：`test` 怎樣才算、`yes` 是、`no` 不是、`how` 怎麼算、`big` 大代表、`small` 小代表、`when` 什麼時候用、`io` 做什麼、`without` 不用會怎樣，或自訂 `<p data-label="名稱">`） | 這個詞本身就是考點，一句話講不完。只寫講得出實質判斷的那幾格；兩個易混淆概念包進 `<div class="defs">` 並排對比 |
| `<div class="calc">` 裡 `class="formula"` 一行、`class="subst"` 一行，結果包 `<span class="ans">` | 算式：公式、代入、黃色螢光筆的答案 | 一步量化計算 |
| `<details class="check"><summary>問題</summary>答案</details>` | 挖空關鍵步自測：先想再打開 | 三階鷹架第 2 階：半完成題或單步關鍵判斷 |
| `<div class="quiz"><p>問題</p><ul><li data-ok>對的</li><li>錯的</li></ul><p class="because">理由</p></div>` | 點選題：選項每次重排，選對出現理由；首答對錯自動記進瀏覽器並支援複製錯題座標 | 配對、Seeing X vs Y 選方法、史料／複雜度辨認 |
| `<details class="answer"><summary>(a) 的做法和答案</summary>…</details>` | 摺起來的完整做法；頁面上有「展開全部做法」 | 三階鷹架第 3 階：讓讀者先白紙獨立解完再對 |
| `<div class="trap">` | 「常見錯誤」 | 有具體誘答或常犯錯法時，寫出錯成什麼、為什麼錯 |
| `<p class="why"><b>問句？</b>答案</p>` | 讀者讀到這裡會問的一個問題 | 不點破就會卡住的「為什麼」 |
| `<div class="sheet">` | 答案紙的樣子（白紙、襯線字） | 考卷或作業上要寫成這樣的那一段（計算結論、申論段落） |
| `<ul class="uses">` | 「這題用到」的清單 | 題目前面列出要用的公式或規則，後面寫 §N |
| `<p class="part">名稱<span>補充</span></p>` | 正文的大分隔，也是目錄上的一組 | 段落多到目錄要分組 |
| `<aside class="panel">` 裡每張 `<figure data-tab="Z 表">` | 頁眉的「查表」，一張一個分頁 | 整張統計表、語法速查表、每題都要對照的規則 |
| `<div class="cheat">` | 速查卡：頁眉隨時打開、可單獨列印，`review.py` 會原樣搬進考前速查 | 讀者考前只看一張的濃縮精華，見〈速查卡和題型表〉 |

- 內文寫「§3.2」就會自動變成側欄預覽連結（`<code>`、`<pre>` 與註解內的 `§` 不會被誤轉），讀者按了在旁邊打開那一段，視線留在原位。
- 讀者按「只看重點」時，頁面只剩標題、`.summary`、`.def`、表格、`.trap` 和寫了 `data-key` 的元素。
- 公式用 MathML（`<div class="formula"><math display="block">…</math></div>`）：Σ 用 `<munderover><mo>∑</mo>下限<mi>n</mi></munderover>`，分數用 `<mfrac>`，括號寫 `<mo stretchy="false">(</mo>`。變數斜體（`<i>T</i><sub>41</sub>`），多字母縮寫正體。
- `<h2>` 標題太長時，目錄用的短標題寫在 `data-short`。

## 速查卡和題型表

**速查卡** `<div class="cheat">`：每份導讀頁一張，讀者考前只看它；使用者說不要才省。裡面的小標用 `<h4>`。

**題型表** `<table class="types">`（用得上才做，放在速查卡裡才會被搬進考前速查）：把 `plan.md` 的**考場題型辨別矩陣（Seeing X vs Y）**寫進來——考試要他做的每一件事一列 `<tr data-type="paired-t">`，清楚列出「看到題幹什麼原文觸發詞／資料長相 → 用哪個方法（及排除哪個易混淆方法）→ 示範 §N」：

- 練習頁和模擬卷的題目寫 `data-type` 對回這一列，`scripts/practice.py` 會列出還沒有題目的題型。
- 學習紀錄照題型記做對、做錯；`scripts/review.py` 把讀者的錯題筆記直接插在那一列下面。
- 答案要靠讀圖或讀程式／軟體輸出的題型加寫 `data-reads="figure"`，練習頁該題型的題目就必須附 `<figure>` 或 `<pre class="output">`。

沒有題型表時，練習頁對回導讀頁的段落（§），學習紀錄照段落記。

## 組頁

```bash
python <tutor目錄>/scripts/build.py guide-src.html -o guide.html
```

`build.py` 加上 § 編號和連結、左邊目錄、頁眉、課件欄（含 `.deck-zh` 譯文層）、名詞表，把圖片和樣式內嵌成離線打得開的單一檔案。會讓頁面或下游壞掉的事不過就不產出，逐條印出原因，照訊息改到通過；公式或表格比正文欄寬時拆行或拆欄。

通過後印三行：產出的路徑、讀完大約幾分鐘（以零基礎 `110 字/分` 加動手題權重估算）、課件欄講到幾頁和沒講到哪幾頁。

## 答案紙

還沒交的作業，導讀頁上要有照老師 Suggested Answers 格式寫的做法和答案。**要交的那一份檔由 `coursework` skill 做**（含盲讀題目與盲做驗算）：

- 評核資料夾已有 `coursework/out/answer.html` 時，它就是單一真相答案紙：導讀頁用 `{{sheet:a}}` 引它，不另寫 `answer-tpl.html`；導讀頁自己算的教學中間數在 `calc.py` 用 `assert` 對齊 `coursework/src/` 的計算結果。
- 還沒有時照下面寫 `answer-tpl.html`，只給導讀頁教學用，不印成要交的檔；在那一節和交付時寫明這份答案未經 `coursework` 盲讀驗證，要交請手動呼叫 `/coursework`。

已交的作業照老師答案講；老師答案還沒出的標明「出了要對一次」。

- 所有算出來的數字由一支計算腳本（`calc.py`）產生，寫成全字串物件 `values.json`。答案紙寫成 `answer-tpl.html`（每題包成 `<div class="part" data-part="a">…</div><!--/part-->`），導讀頁寫成 `guide-tpl.html`，數字用 `{{名稱}}` 佔位，用 `scripts/fill.py` 填入：

```bash
python calc.py                                                                # 寫出 values.json
python <tutor目錄>/scripts/fill.py values.json answer-tpl.html -o answer.html
python <tutor目錄>/scripts/fill.py values.json guide-tpl.html --sheet answer.html -o guide-src.html
```

- 題目本身有給、也能自己重算出來的數字（如報表上已印出的 MSE、F），在 `calc.py` 裡用 `assert` 對一次，對不上表示抄錯題。

## 做法導讀

使用者呼叫 `/tutor <作業>` 要學一份作業怎麼做出來時（[SKILL.md](SKILL.md)〈選分支〉）：

- **已有該單元的導讀頁**：直接在導讀頁裡那份作業的一節補寫（或更新）下面三項，重跑 `scripts/fill.py` 與 `scripts/build.py`。
- **尚無該單元的導讀頁**：照使用者在〈選分支〉選的範圍——若選**輕量單次作業做法頁 `<hw>-guide.html`**，就只針對這份作業會用到的概念、前置符號與下面三項建一頁精簡導讀頁（不掛全章無關課件，也不受全章 `idle=0` 限制）；若選**全章備考導讀頁**，才照 [SKILL.md](SKILL.md) 走完整章節流程再寫這一節。

這一節要做到：讀者照著它，能自己從頭把成品做出來，每一步說得出為什麼。

- **答案引成品**：若有 `coursework/out/answer.html`，照〈答案紙〉用 `{{sheet:…}}` 引它（刪掉舊的教學臨時答案紙範本，`build.sh` 改先跑 `coursework/src/` 的建置腳本）。
- **一段「自己從頭做一次」**：用題目允許、課堂教過的工具，一步一步做出成品上的每個數、每張表或每段輸出。每一步寫齊三件事：**打什麼**（指令、程式碼、公式、選單、儲存格位置與複製範圍都照字面寫全）、**做完該看到什麼**（核對哪一個中間數或輸出）、**為什麼這樣做**（指回講這個方法的 `§N`；題目指定的參數寫明出處）。最後一步教怎麼排成要交的樣子：成品上有的每一欄、每一張表，前面都有一步做出它。
- **寫法是怎麼定的**：題目有幾種讀法時，寫一句是對過題目和老師示範後定的，若有 `coursework/讀法.md` 則指過去，不在頁面上重抄。

**盲做驗收**：寫完後派一個子代理照 [templates/rebuild.md](templates/rebuild.md) 驗收——只給它這份導讀頁原始檔（與引用圖檔）和原始數據，不給成品與計算腳本，確認照字面步驟重做能得出一致的答案且零猜測。找出的缺漏補回導讀頁並重組。
