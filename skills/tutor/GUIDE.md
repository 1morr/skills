# 導讀頁與答案紙

tutor 做材料的分支：照這份寫導讀頁和答案紙。`<S>` 的定義在 SKILL.md。「§N」是導讀頁上的段落編號，由 build 依 `<h2>`、`<h3>` 的順序產生。

## 這一頁要做到什麼

左邊是你寫給這個讀者的講解，右邊的課件欄跟著講解走：他讀到哪，右邊就是老師的那一頁，按一下換成翻譯。

怎麼分段、先講什麼、每段長什麼樣、用哪些元件，照這份材料和這個讀者來定。固定的只有這幾件：

- **每一頁課件都講到**：範圍裡的每一頁，正文都有一個地方指著它（〈課件欄〉）。講多深跟著它在考試裡的份量：會考的講到會做，背景可以幾頁一句帶過。
- **老師的每一題都解**：例題、In-class Exercise、作業、過去的測驗。題目在課件欄，左邊是做法和答案，答案寫成老師的答題格式。題目在課本上的，把題目原文寫進正文。
- **寫成「譯名（原文）」的範圍**：課件上的術語、人名、組織、事件、專有的地名，例如「南進（Nam tiến）」，第二次、第十次也一樣，框裡也一樣；表格的格子、點選題的選項、放不下譯名的標題只寫原文。讀者本來就認得的一般詞（國名、世紀、常見的城市）照讀者的語言寫。

這一頁寫給沒上過課的人：

- 講這一頁課件在說什麼、老師為什麼在這裡講它、和前後怎麼接。課件上的字右邊就看得到，正文用自己的話講它的意思。
- 新概念先用一個小例子算一次或看一次，再給它的名字和公式。
- 每一段最該帶走的東西一眼看得到。
- 形式跟著內容：同一類內容用同一種形式。
- 一個詞、一個人名在介紹之前就要用時，原地給半句它是什麼。

## 課件欄

找完材料就先把讀者要對照的每份檔案做成圖（SKILL.md〈找材料〉第 9 步），在原始檔的資料夾跑：

```bash
uv run --no-project --with pymupdf --with pillow python <S>/deck.py slides \
  L20=<Lecture 20 的 pdf> L21=<Lecture 21 的 pdf> HW3=<作業 3 的 pdf>
```

代號用讀者認得的短名（`L20`、`T6-Summary`、`Eg`、`HW3`）。它寫出每一頁的圖、`slides/slides.json` 和要翻的 `slides/zh.json`；譯文填好再跑一次就有翻譯圖（SKILL.md〈同時開工〉）。參數和檔案格式寫在它開頭。

導讀頁這樣接上課件：

```html
<body data-slides="slides/slides.json">
<h2 data-slide="L20 p.25-28">Reid 把亞洲民族主義分成哪四型？</h2>
<p data-slide="L20 p.28">三個國家各是哪一型……</p>
<tr data-slide="L20 p.29" data-key><td>前身表</td><td>旗子是殖民者；沒有旗子的泰國沒被殖民</td></tr>
```

- `data-slide` 寫在**開始講那一頁的元素**上（標題、段落、表格的一列）。那個元素的開頭捲到畫面上面三分之一時，課件欄停在那一頁、把它框起來，直到下一個 `data-slide`。
- 一段講連續幾頁寫範圍（`L20 p.3-8`）：整個範圍都框起來，課件欄停在第一頁。範圍裡某一頁要在講到它時出現，就在講它的那個元素上再寫那一頁。
- 下一個 `data-slide` 的頁就在旁邊（隔兩頁以內）時，課件欄照他捲動的距離順順地滑過去；隔得遠就等他捲到了才一次跳過去。所以正文照課件的順序走，右邊讀起來像跟著翻頁；跳著講、或回頭指另一份課件，右邊會來回跳。順序由你定，知道這件事再決定；要回頭提別處的一頁，在句子裡寫「L22 p.7」就好，不必用 `data-slide` 把課件欄帶過去。
- `data-key` 標出必記的頁：圖本身就是線索的頁（地圖、圖表、老師強調的那一張）。寫在只指那一頁的元素上（不是範圍、不是 `;` 列的幾頁），這個元素要自己講得完：看到這張圖要認出什麼、考試會怎麼問它。讀者按「只看重點」時留下的是這個元素，旁邊是那一頁課件。
- 寫了 `data-slide` 的元素後面會自動出現那一頁的頁碼標籤，所以正文直接講內容，不用寫「p.17 是……」。不考的頁講的是老師放這幾頁想說什麼，幾頁合成一兩句；逐頁報圖上有什麼會把重點沖淡。
- 課件只給一半的地方（白色字、上課才講的）在正文補上，說明課件上是空白。

build 會印還有哪幾頁「沒講到」：每一頁都要有地方指著它，封面和過場頁併進旁邊那一段的範圍。

**正文裡另外放圖**只在讀者要盯著某一小塊看的時候：統計表上要查的那一格、輸出表上的那個數字、圖上的那條線。用 `<S>/crop.py`（用法在它開頭）截那一小塊，`--box` 畫紅框、`--mark` 標出列與欄，截完用 Read 打開確認框對準了；放在 `<figure>` 裡，`<figcaption>` 寫出處的檔名頁碼。

## 元件

樣式備好了這些，用得到才用；沒列到的直接寫普通的 HTML（表格、清單、`<pre>` 畫的示意圖都有樣式）。框的名字由樣式加上，內文從內容寫起。

| 寫法 | 是什麼 | 適合什麼 |
| --- | --- | --- |
| `<div class="summary">` | 黃底的重點框，名字是「重點」，`data-label="這題記住"` 可以換 | 這一段讀完要帶走的那一兩句 |
| `<dfn>譯名（原文）</dfn>` | 藍色螢光筆的名詞；頁尾自動產生名詞表，照原文排 | 考試會考的術語第一次出現 |
| `<div class="def">` | 上下兩條線的定義框。裡面可以加有名字的格子，一格一個 `<p class="…">`：`test` 怎樣才算、`yes` 是、`no` 不是、`how` 怎麼算、`big` 大代表、`small` 小代表、`when` 什麼時候用、`io` 做什麼、`without` 不用會怎樣；這些名字不合用時寫 `<p data-label="自己取的名字">` | 這個詞本身就是考點，一句話講不完。只寫講得出東西的那幾格；兩個要對照的框包進 `<div class="defs">` 並排 |
| `<div class="calc">` 裡 `class="formula"` 一行、`class="subst"` 一行，結果包 `<span class="ans">` | 算式：公式、代入、黃色螢光筆的答案 | 一步計算 |
| `<details class="check"><summary>問題</summary>答案</details>` | 自測：先想再打開 | 要讀者算一次、寫一句的地方 |
| `<div class="quiz"><p>問題</p><ul><li data-ok>對的</li><li>錯的</li></ul><p class="because">理由</p></div>` | 點選題：選項每次重排，選對了出現理由 | 配對、辨認、選方法這類一眼作答的題型，可以連出很多題 |
| `<details class="answer"><summary>(a) 的做法和答案</summary>…</details>` | 摺起來的做法；頁面上有「展開全部做法」 | 想讓讀者先自己做的題 |
| `<div class="trap">` | 「常見錯誤」 | 有具體的錯法時，寫出錯成什麼 |
| `<p class="why"><b>問句？</b>答案</p>` | 讀者讀到這裡會問的一個問題 | 不講就會卡住的「為什麼」 |
| `<div class="sheet">` | 答案紙的樣子（白紙、襯線字） | 考卷或作業上要寫成這樣的那一段 |
| `<ul class="uses">` | 「這題用到」的清單 | 題目前面列出要用的公式和規則，後面寫 §N |
| `<p class="part">名稱<span>補充</span></p>` | 正文的大分隔，也是目錄上的一組 | 段落多到目錄要分組 |
| `<aside class="panel">` 裡每張 `<figure data-tab="Z 表">` | 頁眉的「查表」，一張一個分頁 | 整張統計表、每題都要對照的規則 |
| `<img src="原圖" data-zh="翻譯圖">` | 點圖換成翻譯 | 正文裡另外放的圖（`crop.py cut --zh`） |
| `<div class="cheat">` | 速查卡：頁眉的「速查卡」隨時在旁邊打開它，可以單獨列印，考前速查會把它原樣搬過去 | 讀者考前只看一張的東西，見〈速查卡和題型表〉 |

- 內文寫「§3.2」就會變成連結，按了在旁邊打開那一段，讀者留在原位。
- 讀者按「只看重點」時，頁面只剩標題、`.summary`、`.def`、表格、`.trap` 和寫了 `data-key` 的元素。考點落在這幾種裡，只看重點的人才看得到；沒有考點的段落這時只剩標題，那樣就對了。
- `.ans` 是算出來的數的螢光筆。
- 公式用 MathML，Σ 的上下限、分數、根號才排得和講義一樣：`<div class="formula"><math display="block">…</math></div>`。Σ 用 `<munderover><mo>∑</mo>下限<mi>n</mi></munderover>`，分數用 `<mfrac>`，括號寫 `<mo stretchy="false">(</mo>`。變數斜體（`<i>T</i><sub>41</sub>`），多個字母的縮寫正體。
- `<h2>` 標題太長時，目錄用的短標題寫在 `data-short`。

## 速查卡和題型表

內容和放哪由你定。

**速查卡** `<div class="cheat">`：每份導讀頁一張，讀者考前只看它；使用者說不要才省。裡面的小標用 `<h4>`。

**題型表** `<table class="types">`（用得上才做）：考試會要他做的每一件事一列，每一列 `<tr data-type="acf-read">` 寫一個英文小寫代號。有這張表，下游就能照題型走：

- 練習頁和模擬卷的題目寫 `data-type` 對回這一列，`practice.py` 會列出還沒有題目的題型。
- 學習紀錄照題型記他做對、做錯；考前速查把他的筆記接在那一列下面（題型表放在速查卡裡才會被搬過去）。
- 答案要靠讀圖或讀軟體輸出的題型再寫 `data-reads="figure"`，練習頁這個題型的題目就必須附圖。

沒有題型表時，練習頁對回導讀頁的段落（§），學習紀錄照段落記。

## 組頁

```bash
python <S>/build.py guide-src.html -o guide.html
```

build 加上 § 編號和連結、左邊的目錄（讀到哪、讀過哪幾段）、頁眉、課件欄、名詞表，把圖片和樣式內嵌成離線打得開的單一檔案。會讓頁面或下游的頁壞掉的事它不產出，逐條印出原因（清單在它開頭），照訊息改到通過；常見的是表格或公式比正文欄寬：拆欄、縮短表頭，或一條公式拆成兩行。

通過後它印三行：產出的路徑、讀完大約幾分鐘、課件欄講到幾頁和沒講到哪幾頁（SKILL.md〈導讀頁和答案紙〉的完成條件）。

## 答案紙

還沒交的作業，導讀頁上要有照老師的 Suggested Answers 格式寫的做法和答案（原文、簡潔、句型照講義）。**要交的那一份檔由 `/1morr:coursework` 做**：它先用沒看過對話的子代理確認題目沒讀錯，做完再盲做驗證，這裡沒有這兩步。

- 評核資料夾有 `coursework/out/answer.html` 時，它就是答案紙：導讀頁用 `{{sheet:a}}` 引它，不另寫 `answer-tpl.html`；導讀頁自己算的數在 `calc.py` 用 assert 對 `coursework/src/` 的計算腳本。
- 沒有時照下面寫 `answer-tpl.html`，只給導讀頁用，不印成要交的檔；在那一節和交付時寫明這份答案是教學用的，要交請叫用 `/1morr:coursework`。

已交的作業照老師答案講；老師答案還沒出的標明「出了要對一次」；還沒發佈的在導讀頁寫一句，發佈後再叫用一次。

- 所有數字由一支計算腳本（`calc.py`）算出來：它只管算，把每個值寫成 `values.json`。答案紙寫成 `answer-tpl.html`，導讀頁寫成 `guide-tpl.html`，數字用 `{{名稱}}` 佔位，用 `<S>/fill.py` 填入；`values.json` 和佔位的格式寫在它開頭。沒有作業、但導讀頁上有算出來的數字時，一樣用這支腳本和佔位。
- 答案紙每一題包成一個 `part`，導讀頁用 `{{sheet:a}}` 把那一段原樣放進 `.sheet`，兩邊就一字不差（`fill.py --sheet`）。

```bash
python calc.py                                                     # 寫出 values.json
python <S>/fill.py values.json answer-tpl.html -o answer.html
python <S>/fill.py values.json guide-tpl.html --sheet answer.html -o guide-src.html
```

- 題目本身有給、也能自己算出來的數字（表上已有的 MSE、F），在 `calc.py` 裡用 assert 對一次，對不上表示抄錯題。

## 做法導讀

`coursework` 做完一份成品後，教學寫在講這個範圍的導讀頁裡那份作業的一節：上面就是每個方法的講解和老師的例題，不另開一頁。還沒有這個範圍的導讀頁時，先照 SKILL.md 的步驟做一份，再回來寫這一節。

這一節要做到：讀者照著它，能自己從頭把成品做出來，每一步說得出為什麼。

- **答案引成品**：照〈答案紙〉用 `{{sheet:…}}` 引 `coursework/out/answer.html`。這一節原本有自己的答案紙範本的，刪掉它，重建腳本改成先跑 `coursework/src/` 的建置腳本，不再另出要交的檔。
- **一段「自己從頭做一次」**：用題目允許、課堂教過的工具，一步一步做出成品上的每個數和每張表。每一步寫三件事：打什麼（公式、選單、格子位置都照字面寫全，起始的那幾格也寫，哪幾格要往下複製到哪一列也寫）、做完該看到什麼（對哪一個數）、為什麼（指回講這個方法的 §；題目給的參數寫明是題目給的）。最後一步教怎麼排成要交的樣子：成品上有的每一欄、每一張表，前面都有一步做出它。
- **寫法是怎麼定的**：成品的寫法有幾種讀法時，寫一句是對過題目和老師的示範後定的，指到 `coursework/讀法.md`；不在頁面上重抄一份。

驗證由 `coursework` 做（它的〈教學〉）：一個只拿到這份導讀頁原始檔和原始數據的子代理照著重做。
