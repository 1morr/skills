# 導讀頁與答案紙

tutor 做材料的分支：SKILL.md〈找材料〉〈範圍〉做完之後，照這份寫導讀頁和答案紙。`<S>` 的定義在 SKILL.md。這份裡的「§N」都是導讀頁上的段落編號。

## 寫法：讓小學生也看得懂

這幾條是整頁的寫法，每一條都比內容完整更優先：

1. **先舉例，再給名字**：新概念先用一個生活情境和 3–5 個小整數，在原地算一次或畫一次，再說「這叫做○○」。例如先用 1, 5, 1, 5, 1, 5 把序列往右挪一格配對，算出 r₁ = −20/24 = −0.83（隔一期總是相反），再講 Σ 是什麼意思。小例子的答案要和直覺同方向：讀者一眼看得出「很像」的，算出來就要接近 1。
2. **每個術語一個定義框**（`<div class="def">`，術語用 `<dfn>`）：「是什麼」一句，`class="test"` 寫「怎樣才算」，要是讀者能拿來檢查的標準，再給一個「是」的例子、一個「不是」的例子。課件只給名詞時，用課本的定義（附頁碼）。**先教再用**：在定義之前就要用到的詞（例如「平均」「顯著」），先在原地給一句白話，再說「詳細在 §N」。
   - **前置知識搬進來，不指出去**：之前 topic 或其他課的東西（例如 Topic 5 用到 Topic 4 的 ACF、MAPE；統計課用到的標準差、假設檢定）在第一次用到的地方從零教：定義框、小整數算一次，再把**那個 topic 的課件那一塊截過來**（附翻譯圖，figcaption 寫檔名頁碼；不用列進 `data-pages`）。只補這裡需要的那一點。提出處時寫成「這是 Topic 4 Summary p.3 的公式，這裡從零算一次」；把讀者指去別處的句子（「見 Topic 4」「之前學過」）build 不產出。
3. **符號小抄**：課件欄最前面一段，用小整數在原地教一次這個 topic 會用到的符號和算法，例如負數、平方、√、小數和百分比、分數、Σ、下標、怎麼讀圖的橫軸縱軸。只教這個 topic 用得到的。
4. **公式每次都寫全**：`<div class="calc">` 裡一行 `class="formula"` 寫公式，下一行 `class="subst"` 代入數字並算出答案，算出來的那個數包成 `<span class="ans">`（螢光筆，讀者掃一眼就找到每一步的結果）。不寫「用 §N 的公式」；加總不用「…」省略項目，項目多就列成表，表上每一項都看得到。代入時先寫出每一項再算：寫 (−4)² + (−2)² + … = 16 + 4 + …，不要直接寫 16 + 4 + …。手算的示範表，公式裡每個中間量各一列（例如離差、往右挪 k 格的離差、兩者相乘、離差平方），最後一欄是總和，讀者照著表就能自己算一遍。
5. **一段只講一件新東西，一句最多 50 字**（build 會量）。一句一件事，長句拆成兩句。每個符號第一次出現就說怎麼唸、代表什麼。新詞第一次出現寫成「讀者的語言（原文）」，例如「趨勢（trend）」。比喻只在概念太抽象時用一個，馬上回到課件的寫法。
6. **重點先講，講完自己做**：課件欄每個 `<h2>` 底下先放「這頁重點」（`<div class="summary">`，最多 3 點：學到什麼、怎麼判斷、考試怎麼問），讀者先知道要帶走什麼再讀細節；結尾放自測（`<details class="check">`，見〈導讀頁〉）。題目欄每題結尾放「這題記住」（同一個 `.summary`）。題目欄最後一段是 `<h2 class="recap">` 整個 topic 的總結：做題的流程，和整個 topic 最要記的幾點（「看到什麼 → 用什麼」的判斷表放在題目欄開頭，見〈導讀頁〉）。

改寫前後的樣子：

- 前：「趨勢（trend）是資料長期的方向。」
- 後：先給 12 個月的銷量 120, 123, 128, …，畫出來整體往上；再放定義框：**趨勢**＝長期往一個方向走。怎樣才算：前半的平均明顯比後半低（或高），而且不是一兩個怪點撐起來的；ACF 的 r₁ 接近 1、之後慢慢往下降。是：人口逐年增加。不是：只有某個月暴增、其他月份持平（那是不規則變動）。

寫完一段，假裝自己什麼都不懂再讀一次：還會問「為什麼」「這個數字哪來的」「怎樣才算」「換一題要怎麼知道」，就是還沒寫完。交付前還有一位沒看過材料的讀者會驗一次（SKILL.md〈驗證〉）。

## 導讀頁：左欄課件、右欄題目

頁面分兩欄，螢幕夠寬時左右並排、各自捲動：讀者學到課件哪裡就看右欄對應的題目。**右欄要能單獨做題**，不叫讀者跳去左欄找（每題要寫全什麼，見下面骨架第 1 步）。§ 連結只留「想看完整推導再點」的；點了會讓左欄跳過去，畫面右下角出現「回到剛才」，按一下兩欄都回到跳之前的位置。

```html
<body data-pages="..." data-problems="calc">
<section class="course">   標題、範圍表、符號小抄、講義導讀（第一部分）</section>
<section class="problems"> 題型表、例題（第二部分）、作業（第三部分）、整個 topic 的總結</section>
</body>
```

`data-problems` 是題目欄的型態：`calc`（預設，算題：每題要有「數字從哪來」和算式）或 `text`（文科：答案是要點和句子，見下面「文科課程」）。

§ 編號兩欄連續（左欄 §1–§12、右欄 §13 起），使用者說「卡在 §15」就知道是哪題。

### 第一部分（左欄）：講義導讀

講義每一頁一個 `<h2>`。標題寫成這頁在回答的問題，頁碼放括號，例如「今天和昨天有沒有關係？自相關 rₖ（講義 p.3）」。只寫課件檔名的話，「Summary p.3」會被讀成「總結」。每頁照這個順序：

1. **看整頁**：`<details><summary>看整頁</summary>` 裡放整頁圖（`<figure class="page">`，附翻譯圖）。預設摺起來，給想對照原稿的人。
2. **這頁重點**（`.summary`，放在第一個 `<h3>` 之前）：最多 3 點，接一兩句話說這頁分幾塊。
3. **逐塊講解**：課件上的一塊（一個標題、一條公式、一條規則）一個 `<h3>`，從上講到下，直到這頁結束。每塊依序放：
   - 例子：生活情境和小整數，先算一次或畫一次（〈寫法〉第 1 條）。
   - 定義框（〈寫法〉第 2 條）。
   - 這塊的截圖，附翻譯圖（紅框圈出要看的地方）。
   - 講解：公式為什麼長這樣，從讀者已經懂的東西一步步推，每一塊（分子、分母、平方、減 1）在做什麼、拿掉會怎樣；算出來的數字大代表什麼、小代表什麼。用直覺推，不寫證明。
   - 課件上有門檻或常數（例如 |*r*| ≥ 0.7、DW 1.5–2.5）時，用「數字從哪來」表交代（格式見題目骨架第 4 步）。
   - 自測（`<details class="check">`）：這一塊有公式、規則或判斷標準時，換一組小數字讓讀者自己算一次或判斷一次。問題寫在 `<summary>`，要讀者給出一個數字或一個名稱；答案和一句原因摺在裡面。
4. **這一頁的自測**：整段最後一塊是 `details.check`，問這一頁最會考的那一件事，不重複上面問過的數字。

用到這頁的例題和作業題，在講解裡寫一句「Eg 2（§15）就是在算這個」，讓讀者能跳到右欄。

### 第二部分（右欄）：例題；第三部分（右欄）：作業

例題和作業題用同一個骨架，每題一個 `<h2>`，標題寫這題要你做什麼（例如「Eg 2：手算落後 2 期的自相關係數 r₂」）。作業依狀態處理：

- 還沒交：照〈答案紙〉做，講解頁每題放「答案紙上寫這樣」。
- 已交、老師答案出了：照老師答案講，答案紙那一步截老師答案（附翻譯圖），不另外寫。
- 已交、老師答案還沒出：照講義格式寫，標明「老師答案還沒出，出了要對一次」。
- 還沒發佈：不寫段落，在範圍表下面寫一句「Assignment N 還沒發佈，發佈後叫 `/1morr:tutor Assignment N`」。

同一個題型第一次出現的那一題，做法每一步寫全。第二題起改成**補完**：前面的步驟照寫，最後一兩步（代入、查表、比較、結論句）各包進一個 `details.check`，問題寫「這一步代入後是多少？」，讀者先自己做那一步再打開。越後面的題留給讀者的步驟越多。

題目欄的開頭（第一個 `<h2>` 之前）放**速查卡** `<div class="cheat">`：讀者考前只看這一張，也可以按工具列的「列印速查卡」單獨印出來。卡上依序是題型表、要背的公式（每條一行，用下面〈版面〉的 MathML 寫法）、判斷規則（門檻和「看到什麼 → 下什麼結論」）。每個小標用 `<h4>`。

**題型表** `<table class="types">`：考點清單（SKILL.md〈找材料〉）的每一項一列，`<tr data-type="acf-read">` 寫一個英文小寫代號，練習頁和模擬卷的題目用它對回這一列。答案要靠讀圖或讀軟體輸出的題型（描述圖形、讀 ACF、讀 ANOVA 表），那一列再寫 `data-reads="figure"`，練習頁這個題型的題目就必須附圖。欄位是「看到什麼題目 → 用哪條公式、查哪張表 → 示範題 §N（右欄的例題或作業）」。趕時間的人從這張表起步，直接做示範題，卡住才去左欄。

每題的骨架：

1. **為什麼**（`<div class="why">`）：這題在問什麼現實問題。接著把這題用到的東西**在這裡寫全**：每個概念一句白話（它是什麼、怎樣才算），公式整條寫出，再放**課件那一塊的截圖**（`<figure>`，附翻譯圖，紅框圈出公式或規則）；讀者只看這一段就能開始做。然後寫這題才有的提示，例如「k = 2 所以從 t = 3 開始加」「n 只數有預測的週」。左欄的 §N 只寫一個「完整推導在 §N」，整題最多連到左欄 3 段。作業題再加一句：和哪一題例題同類、哪裡不一樣。寫到提示為止：結論（「lag 4 顯著，所以有季節性」）是答案，留在 `details.answer` 裡。
2. **題目**：只截這一題的題目全文和表格，附翻譯圖。Minitab 的欄名列名（Source、DF、SS…）、統計表的列和欄也要翻。
3. **做法和答案**：下面第 4–8 步收進 `<details class="answer"><summary>做法和答案</summary>…</details>`，讀者先自己做。題目有好幾小題時，**每一小題各一個** `details.answer`（摘要寫「(a) 的做法和答案」），讀者做完一小題只打開那一小題，不會順便看到後面的答案。做下一小題要用到的圖（例如 (a) 畫出的時間序列圖，(b) 要看它判斷），放在下一小題的摺疊外面。頁面頂端有「展開全部做法」的按鈕，只想讀的人按一下就全部打開。
4. **數字從哪來**（`<table class="origin">`，`<caption>這題要用的數字從哪來</caption>`）：排在這一題**第一個算式前面**，做題的順序就是「先找齊數字，再代公式」，讀者算到那一步時已經知道每個數字的來源。欄位是「值｜從哪來｜換一題怎麼找」。**只列不明顯的數字**；題目直接給的、上面算出來的不列。每一列在 `<tr>` 寫 `data-from` 說是哪一種：
   - `table`（查表）：哪張表、哪一列哪一欄，列和欄的值又各自從哪來；連到這一段圈出那一格的 `<figure>`（`<a href="#圖的id">`），並寫出左欄講這張表的 §N。
   - `count`（要自己數的，例如 n、df）：怎麼數、容易數錯成什麼；連到數它用的圖或 `.calc`（給 `.calc` 一個 `id`）。
   - `convention`（慣例，例如 α = 0.05）：說明這是大家約定的，不是算出來的；為什麼常用這個值；題目怎樣寫就要換（「at the 1% level」→ 0.01）；題目沒寫時老師用什麼。
   - `rule`（經驗法則，例如 DW 在 1.5–2.5 之間）：誰定的（老師講義或課本）、背後的道理、別的書可能用別的門檻，考試照老師。
   - `constant`（公式裡的常數，例如 *n* − *k* − 1 的 1）：它代表什麼。
5. **套到這題**：一步一步算，每一步一個 `.calc`（公式一行、代入一行）。代入那一行之前用一句話交代代進去的數字（「*n* = 36：資料有 3 欄 × 12 期」），不要只寫「*n* = 36」。用到的數字在材料上看得到時（題目、軟體輸出、統計表、講義），就在這一段放那份材料的截圖，紅框圈出那幾個數字，查表用 `--mark` 標出列與欄。前一段放過同一張也要再放：讀者不該往上翻找數字。統計表只截圈出的那一格附近（表頭、那一列和上下各兩列），整張表放查表面板（見〈版面〉）。
   - 數字由軟體算出時（例如 Minitab 的 *r<sub>k</sub>*），至少用這題的資料手算其中一個，列成〈寫法〉第 4 條的示範表，說一句「Minitab 就是照這個公式算的」；資料太多時，連到手算同一種數字的那一題（例如「怎麼算見 Eg 2，§22」）。
6. **答案紙上寫這樣**：放在 `<div class="sheet">` 裡，內容和答案紙上的那段一模一樣。下面用一兩句讀者的語言說每句原文在說什麼。步驟在第 5 步算過了，這裡只放答案紙上的那段。
7. **常見錯誤**（`<div class="trap">`，有才寫）：給出具體的錯數字，例如「把 n 算成 8 會得到 …」。
8. **這題記住**（`.summary`，放在 `details.answer` 的最後）。

### 文科課程

歷史、哲學、通識這類答案是要點和句子的課，`<body>` 寫 `data-problems="text"`，題目欄的骨架照 [TEXT.md](TEXT.md)。

### 版面

- 有底色的框四種：定義（`.def`）、重點（`.summary`）、常見錯誤（`.trap`）、譯文（`.tr`，只在做不出翻譯圖時用）。「為什麼」是有標籤的普通段落。這些框和答案紙（`.sheet`）的標籤由樣式加上：內文直接寫內容，開頭不再寫「為什麼：」「常見錯誤：」。
- 強調只有兩種，用多了就等於沒有：`.ans` 標每個算式算出來的數；`<strong>` 標一段裡讀者最該帶走的那個詞或門檻（「**n − k** 項」「**落在區間外**就拒絕」），一段最多一處。
- 公式行用 MathML，Σ 的上下限、分數、根號就會排得和講義一樣；代入行可以用 `<span class="frac">`。寫成 `<div class="formula"><math display="block">…</math></div>`：Σ 用 `<munderover><mo>∑</mo>下限<mi>n</mi></munderover>`，分數用 `<mfrac>`，ȳ 用 `<mover><mi>y</mi><mo>¯</mo></mover>`，括號寫 `<mo stretchy="false">(</mo>` 才不會被 Σ 撐高。
- 查表面板：整張統計表、每題都要對照的規則截圖放進 `<body>` 底下的 `<aside class="panel">`，每張 `<figure data-tab="Z 表">` 一個分頁。讀者按題目欄的「查表」打開，不用每題重貼整張表。
- 圖預設不超過畫面高的六成，圖說上有「放大」。截圖只截要講的那一塊；一張圖高過一個畫面，就是截太多了。
- 課件欄開頭寫：這頁要讀多久、怎麼讀、範圍表、符號小抄。題目欄開頭是速查卡，最後寫：「卡在哪就說 §編號」。目錄、工具列和「回到剛才」由 build 產生（見〈截圖與組頁〉）。

### 截圖與組頁

截圖用 `<S>/crop.py`：先用 `find` 或 `lines` 找座標（掃描檔用 `grid`），再用 `cut` 截。每個子指令的參數、座標單位和翻譯檔的格式寫在它開頭。

```bash
CROP="uv run --no-project --with pymupdf --with pillow python <S>/crop.py"
$CROP cut 講義.pdf 4 out.png --clip 70,80,560,430 --box 90,250,540,280 --zh zh/summary.json
```

`--box` 畫紅框（要看這裡），`--mark` 塗淡黃（查表時的列與欄）。截完一定要用 Read 打開圖看一次，確認框對準了。

每張圖都放在 `<figure>` 裡，`<figcaption>` 寫出處（檔名與 `p.頁碼`）。數字從哪來要連到的圖，給 `<figure>` 一個 `id`。

頁面寫成原始 HTML，圖片用相對路徑。再用 `<S>/build.py` 組成單一檔案：

```bash
python <S>/build.py guide-src.html -o guide.html
```

build 也會內嵌圖片、加上共用樣式、替 `<h2>` / `<h3>` 編號（§1、§1.2）、在每一欄開頭產生目錄和工具列（現在讀到哪一段、圖片中英切換、查表、列印速查卡、展開全部做法）、把內文的「§3.2」變成連結：這些都不用自己寫。它檢查這份的結構與寫法規則，任何一條不過就不產出，並逐條印出違反哪一條、為什麼；照訊息改到通過。組好之後它用無頭瀏覽器在寬螢幕和手機寬各量一次水平溢出，有就不產出：照它列的元素，把寬的公式放進 `.formula`、寬的表格拆欄，或讓那段文字換行。正文太長或沒摺起來的圖太多時會印「提醒」（不擋產出）：照提醒刪減，讀者才抓得到重點。

## 答案紙：和講解分開

- 答案紙是一份要交的檔案，照老師的 Suggested Answers 格式寫：英文、簡潔，句型照講義。用 HTML 寫，再用 Chrome headless 印成 PDF（`--print-to-pdf`）。
- 所有數字都由一支計算腳本（`calc.py`）算出來：它只管算，把每個值寫成 `values.json`。答案紙寫成 `answer-tpl.html`，講解頁寫成 `guide-tpl.html`，數字用 `{{名稱}}` 佔位，用 `<S>/fill.py` 填入；`values.json` 和佔位的格式寫在它開頭。
- 答案紙每一題包成一個 `part`，講解頁用 `{{sheet:a}}` 把那一段原樣放進來，兩邊就一字不差（`fill.py --sheet`，寫法也在它開頭）。

```bash
FILL="python <S>/fill.py"
python calc.py                                                     # 寫出 values.json
$FILL values.json answer-tpl.html -o answer.html
$FILL values.json guide-tpl.html --sheet answer.html -o guide-src.html
```

- 題目本身有給、也能自己算出來的數字（例如表上已有的 MSE、F），在 `calc.py` 裡用 assert 對一次，對不上表示抄錯題。
