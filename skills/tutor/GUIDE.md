# 導讀頁與答案紙

tutor 做材料的分支：SKILL.md〈找材料〉〈範圍〉做完之後，照這份寫導讀頁和答案紙。`<S>` 的定義在 SKILL.md。這份裡的「§N」都是導讀頁上的段落編號。

## 寫法：讓小學生也看得懂

這幾條是整頁的寫法，每一條都比內容完整更優先：

1. **先舉例，再給名字**：新概念先用一個生活情境和 3–5 個小整數，在原地算一次或畫一次，再說「這叫做○○」。例如先用 1, 5, 1, 5, 1, 5 把序列往右挪一格配對，算出 r₁ = −20/24 = −0.83（隔一期總是相反），再講 Σ 是什麼意思。小例子的答案要和直覺同方向：讀者一眼看得出「很像」的，算出來就要接近 1。
2. **每個術語一個定義框**（`<div class="def">`）：第一段寫 `<dfn>原文</dfn>（讀者的語言）` 和「是什麼」一句，例如 `<dfn>seasonal index</dfn>（季節指數）`。下面三格照這個術語是哪一種寫，種類寫在框上的 `data-kind`，每格一個 `<p class="…">`：

   | 術語是 | `data-kind` | 三格（class：頁面上的名字，寫什麼） |
   | --- | --- | --- |
   | 要分辨的東西（趨勢、季節變動、平穩） | `class`（沒寫就是它） | `test`：怎樣才算，讀者能拿來檢查的標準。`yes`：是，一個例子。`no`：不是，最容易和它搞混的那一個，並寫出它其實是什麼 |
   | 一個量（季節指數、移動平均、*r<sub>k</sub>*） | `quantity` | `how`：怎麼算，用小整數算一次。`big`：大代表什麼。`small`：小代表什麼 |
   | 一個方法或流程（時間序列分解、比率移動平均法） | `method` | `when`：什麼時候用。`io`：做什麼，拿什麼進去、得到什麼。`without`：不用會怎樣 |

   考試用原文，所以原文在前；頁尾的名詞表由 `<dfn>` 和它後面的括號產生。兩個要對照著看的術語（加法模型和乘法模型）包進 `<div class="defs">` 並排。課件只給名詞時，用課本的定義（附頁碼）。**先教再用**：在定義之前就要用到的詞（例如「平均」「顯著」），先在原地給一句白話，再說「詳細在 §N」。
   - **前置知識搬進來，不指出去**：之前 topic 或其他課的東西（例如 Topic 5 用到 Topic 4 的 ACF、MAPE；統計課用到的標準差、假設檢定）在第一次用到的地方從零教：定義框、小整數算一次，再把**那個 topic 的課件那一塊截過來**（附翻譯圖，figcaption 寫檔名頁碼；不用列進 `data-pages`）。只補這裡需要的那一點。提出處時寫成「這是 Topic 4 Summary p.3 的公式，這裡從零算一次」；把讀者指去別處的句子，常見的說法（「見 Topic 4」「之前學過」）build 會擋，其餘的說法由你自己守。
3. **符號小抄**：講義那部最前面一段，用小整數在原地教一次這個 topic 會用到的符號和算法，例如負數、平方、√、小數和百分比、分數、Σ、下標、怎麼讀圖的橫軸縱軸。只教這個 topic 用得到的。
4. **公式每次都寫全**：`<div class="calc">` 裡一行 `class="formula"` 寫公式，下一行 `class="subst"` 代入數字並算出答案，算出來的那個數包成 `<span class="ans">`（螢光筆，讀者掃一眼就找到每一步的結果）。不寫「用 §N 的公式」；加總不用「…」省略項目，項目多就列成表，表上每一項都看得到。代入時先寫出每一項再算：寫 (−4)² + (−2)² + … = 16 + 4 + …，不要直接寫 16 + 4 + …。手算的示範表，公式裡每個中間量各一列（例如離差、往右挪 k 格的離差、兩者相乘、離差平方），最後一欄是總和，讀者照著表就能自己算一遍。
5. **一段只講一件新東西，一句最多 50 字**（build 會量）。一句一件事，長句拆成兩句。每個符號第一次出現就說怎麼唸、代表什麼。新詞第一次出現寫成「原文（讀者的語言）」，例如「trend（趨勢）」，之後可以只寫讀者的語言。比喻只在概念太抽象時用一個，馬上回到課件的寫法。
6. **重點先講，講完自己做**：講義那部每個 `<h2>` 底下先放「這頁重點」（`<div class="summary">`，最多 3 點：學到什麼、怎麼判斷、考試怎麼問），讀者先知道要帶走什麼再讀細節；結尾放自測（`<details class="check">`，見〈導讀頁〉）。題目那部每題結尾放「這題記住」（同一個 `.summary`）。題目那部最後一段是 `<h2 class="recap">` 整個 topic 的總結：做題的流程，和整個 topic 最要記的幾點（「看到什麼 → 用什麼」的判斷表放在題目那部開頭，見〈導讀頁〉）。

改寫前後的樣子：

- 前：「trend（趨勢）是資料長期的方向。」
- 後：先給 12 個月的銷量 120, 123, 128, …，畫出來整體往上；再放定義框：**trend**（趨勢）＝長期往一個方向走。怎樣才算：前半的平均明顯比後半低（或高），而且不是一兩個怪點撐起來的；ACF 的 r₁ 接近 1、之後慢慢往下降。是：人口逐年增加。不是：只有某個月暴增、其他月份持平（那是不規則變動）。

另外兩種定義框寫好的樣子：

- 一個量：**seasonal index**（季節指數）＝某一季比一般季高多少、低多少，以 100 為基準。怎麼算：第 1 季平均 7 ÷ 總平均 10 × 100 = 70。大代表：高於 100 是旺季，130 就是比一般季多 30%。小代表：低於 100 是淡季，70 就是少 30%。
- 一個方法：**ratio-to-moving-average method**（比率移動平均法）＝拿每一季和它附近一年的平均比。什麼時候用：資料有趨勢。做什麼：進去是每季的 *Y*，出來是四個季節指數。不用會怎樣：直接用季平均 ÷ 總平均，越後面的年水準越高，排在年尾的那一季會被墊高。

## 導讀頁：一本只有一條捲軸的課本

原始檔分兩部，組好的頁把它們接成一條捲軸：左邊是固定的目錄，中間是正文，右邊是**對照欄**。

```html
<body data-pages="..." data-problems="calc">
<section class="course">   標題、範圍表、符號小抄、講義導讀（第一部分）</section>
<section class="problems"> 速查卡、例題（第二部分）、作業（第三部分）、整個 topic 的總結</section>
</body>
```

- **教學只寫一次**，寫在講義那部、有上下文的地方。題目只列用到什麼，後面寫講義的 §N（見下面骨架第 1 步）；讀者按 §N，那一段原文就在對照欄打開，題目留在原位。
- 引用段落時，內文寫「§3.2」。
- `data-problems` 是題目那部的型態：`calc`（預設，算題：每題要有「數字從哪來」和算式）或 `text`（文科：答案是要點和句子，見下面「文科課程」）。
- § 編號兩部連續（講義 §1–§12、題目 §13 起），使用者說「卡在 §15」就知道是哪題。
- 題目那部裡，例題和作業各用一行 `<p class="part">例題</p>`、`<p class="part">作業<span>Assignment 5，11/17 交</span></p>` 起頭：它是正文裡的分隔，也是目錄上的一組。

### 第一部分：講義導讀

講義每一頁一個 `<h2>`。標題寫成這頁在回答的問題，頁碼放括號，例如「今天和昨天有沒有關係？自相關 rₖ（講義 p.3）」。只寫課件檔名的話，「Summary p.3」會被讀成「總結」。目錄上的短標題是去掉尾巴頁碼的標題；還是太長就在 `<h2 data-short="自相關 rₖ">` 另外寫一個。每頁照這個順序：

1. **看整頁**：`<details><summary>看整頁</summary>` 裡放整頁圖（`<figure class="page">`，附翻譯圖）。預設摺起來，給想對照原稿的人。
2. **這頁重點**（`.summary`，放在第一個 `<h3>` 之前）：最多 3 點，接一兩句話說這頁分幾塊。
3. **逐塊講解**：課件上的一塊（一個標題、一條公式、一條規則）一個 `<h3>`，從上講到下，直到這頁結束。每塊依序放：
   - 例子：生活情境和小整數，先算一次或畫一次（〈寫法〉第 1 條）。
   - 定義框（〈寫法〉第 2 條）。
   - 這塊的截圖，附翻譯圖（紅框圈出要看的地方）。
   - 講解：講到截圖上的每一句，照這一塊是什麼來寫。
     - 公式：它為什麼長這樣，從讀者已經懂的東西一步步推，每一塊（分子、分母、平方、減 1）在做什麼、拿掉會怎樣；算出來的數字大代表什麼、小代表什麼。用直覺推，不寫證明。
     - 概念或列表：課件的每一句、每一點各對一句講解，說它的意思，和它在這個 topic 的例子裡是哪個數字或哪一段。接著寫考試怎麼問這一點、答案要寫出哪幾個字。
     - 圖：怎麼讀（橫軸、縱軸、每條線是什麼），要看哪裡，看到之後下什麼結論。
   - 「為什麼」（`.why`）：讀者讀到這裡會問的一個問題，和它的答案。開頭寫出那個問題：`<p class="why"><b>為什麼不直接用季平均 ÷ 總平均？</b>…</p>`。一個框答一個問題；答案和數字有關時，拿這一塊的例子再算一次（「每季都加 4 之後，第 4 季的指數從 40 變成 44」）。
   - 課件上有門檻或常數（例如 |*r*| ≥ 0.7、DW 1.5–2.5）時，用「數字從哪來」表交代（格式見題目骨架第 4 步）。
   - 自測（`<details class="check">`）：這一塊有公式、規則或判斷標準時，換一組小數字讓讀者自己算一次或判斷一次。問題寫在 `<summary>`，要讀者給出一個數字或一個名稱。摺在裡面的答案要教會答不出來的人，每一小問寫四樣：答案；線索（題目裡哪幾個字，算題就是算式的每一步）；它對到這一頁的哪一條規則或哪個定義框；最容易答錯成什麼、為什麼不對。最後一行「還不會：回 §N.M」。
   一塊寫完的條件：截圖上的每一句都有一句講解對到；「這塊在回答什麼問題、怎麼算或怎麼判斷、為什麼是這樣、考試怎麼問」四樣，各指得出是這一塊的哪一句。
4. **這一頁的自測**：整段最後一塊是 `details.check`，問這一頁最會考的那一件事，不重複上面問過的數字，答案的寫法同上。自測只問這一頁教過的判斷：答案用到的每一條規則，在這一頁指得出是哪一句。

用到這頁的例題和作業題，在講解裡寫一句「Eg 2（§15）就是在算這個」。

### 第二部分：例題；第三部分：作業

例題和作業題用同一個骨架，每題一個 `<h2>`，標題寫這題要你做什麼（例如「Eg 2：手算落後 2 期的自相關係數 r₂」）。作業依狀態處理：

- 還沒交：照〈答案紙〉做，講解頁每題放「答案紙上寫這樣」。
- 已交、老師答案出了：照老師答案講，答案紙那一步截老師答案（附翻譯圖），不另外寫。
- 已交、老師答案還沒出：照講義格式寫，標明「老師答案還沒出，出了要對一次」。
- 還沒發佈：不寫段落，在範圍表下面寫一句「Assignment N 還沒發佈，發佈後叫 `/1morr:tutor Assignment N`」。

同一個題型第一次出現的那一題，做法每一步寫全。第二題起改成**補完**：前面的步驟照寫，最後一兩步（代入、查表、比較、結論句）各包進一個 `details.check`，問題寫「這一步代入後是多少？」，讀者先自己做那一步再打開。越後面的題留給讀者的步驟越多。

題目那部的開頭（第一個 `<h2>` 之前）放**速查卡** `<div class="cheat">`：讀者考前只看這一張，做題時按頁眉的「速查卡」在對照欄打開，也可以單獨印出來。卡上依序是題型表、要背的公式（每條各寫一個 `<div class="formula">`，用下面〈版面〉的 MathML 寫法；頁面會把短的並排、放不下就換行）、判斷規則（門檻和「看到什麼 → 下什麼結論」）。每個小標用 `<h4>`。考場會發公式表時（SKILL.md〈找材料〉第 7 步），公式那一段的小標寫「公式（考場會發）」；不發的才叫「要背的公式」。

**題型表** `<table class="types">`：考點清單（SKILL.md〈找材料〉）的每一項一列，`<tr data-type="acf-read">` 寫一個英文小寫代號，練習頁和模擬卷的題目用它對回這一列。答案要靠讀圖或讀軟體輸出的題型（描述圖形、讀 ACF、讀 ANOVA 表），那一列再寫 `data-reads="figure"`，練習頁這個題型的題目就必須附圖。欄位是「看到什麼題目 → 用哪條公式、查哪張表 → 示範題 §N（例題或作業）」。趕時間的人從這張表起步，直接做示範題，卡住才按 §N 看講義。

每題的骨架：

1. **這題用到**：先用一句話寫這題在問什麼現實問題。接著 `<ul class="uses">`，一行列一樣這題用到的東西：公式整條寫出，或一句規則，後面寫它在講義的 §N，例如 `<li>預測 = <i>S</i> × <i>T</i>（為什麼只乘這兩個：§6.4）</li>`。前面題目算好、這題要接著用的數字也列在這裡（「趨勢線 <i>Ŷ</i> = 283.8 + 6.2<i>t</i>，§10 算的」）。只列，不講解：定義、推導、課件截圖都留在講義那一段，題目旁邊再寫一份較短的，讀者反而看不到上下文。這題才有的提示（「k = 2 所以從 t = 3 開始加」）收進 `<details><summary>提示：卡住再看</summary>`。作業題再加一句：和哪一題例題同類、哪裡不一樣。結論（「lag 4 顯著，所以有季節性」）是答案，留在 `details.answer` 裡。
2. **題目**：只截這一題的題目全文和表格，附翻譯圖。Minitab 的欄名列名（Source、DF、SS…）、統計表的列和欄也要翻。
3. **做法和答案**：下面第 4–8 步收進 `<details class="answer"><summary>做法和答案</summary>…</details>`，讀者先自己做。題目有好幾小題時，**每一小題各一個** `details.answer`（摘要寫「(a) 的做法和答案」），讀者做完一小題只打開那一小題，不會順便看到後面的答案。做下一小題要用到的圖（例如 (a) 畫出的時間序列圖，(b) 要看它判斷），放在下一小題的摺疊外面。頁面頂端有「展開全部做法」的按鈕，只想讀的人按一下就全部打開。
4. **數字從哪來**（`<table class="origin">`，`<caption>這題要用的數字從哪來</caption>`）：排在這一題**第一個算式前面**，做題的順序就是「先找齊數字，再代公式」，讀者算到那一步時已經知道每個數字的來源。欄位是「值｜從哪來｜換一題怎麼找」。**只列不明顯的數字**；題目直接給的、上面算出來的不列。每一列在 `<tr>` 寫 `data-from` 說是哪一種：
   - `table`（查表）：哪張表、哪一列哪一欄，列和欄的值又各自從哪來；連到這一段圈出那一格的 `<figure>`（`<a href="#圖的id">`），並寫出講義講這張表的 §N。
   - `count`（要自己數的，例如 n、df）：怎麼數、容易數錯成什麼；連到數它用的圖或 `.calc`（給 `.calc` 一個 `id`）。
   - `convention`（慣例，例如 α = 0.05）：說明這是大家約定的，不是算出來的；為什麼常用這個值；題目怎樣寫就要換（「at the 1% level」→ 0.01）；題目沒寫時老師用什麼。
   - `rule`（經驗法則，例如 DW 在 1.5–2.5 之間）：誰定的（老師講義或課本）、背後的道理、別的書可能用別的門檻，考試照老師。
   - `constant`（公式裡的常數，例如 *n* − *k* − 1 的 1）：它代表什麼。
5. **套到這題**：一步一步算，每一步一個 `.calc`（公式一行、代入一行）。代入那一行之前用一句話交代代進去的數字（「*n* = 36：資料有 3 欄 × 12 期」），不要只寫「*n* = 36」。用到的數字在材料上看得到時（題目、軟體輸出、統計表、講義），就在這一段放那份材料的截圖，紅框圈出那幾個數字，查表用 `--mark` 標出列與欄。前一段放過同一張也要再放：讀者不該往上翻找數字。統計表只截圈出的那一格附近（表頭、那一列和上下各兩列），整張表放查表面板（見〈版面〉）。
   - 數字由軟體算出時（例如 Minitab 的 *r<sub>k</sub>*），至少用這題的資料手算其中一個，列成〈寫法〉第 4 條的示範表，說一句「Minitab 就是照這個公式算的」；資料太多時，連到手算同一種數字的那一題（例如「怎麼算見 Eg 2，§22」）。
6. **答案紙上寫這樣**：放在 `<div class="sheet">` 裡，內容和答案紙上的那段一模一樣。下面用一兩句讀者的語言說每句原文在說什麼。步驟在第 5 步算過了，這裡只放答案紙上的那段。
7. **常見錯誤**（`<div class="trap">`，有才寫）：給出具體的錯數字，例如「把 n 算成 8 會得到 …」。
8. **這題記住**（`.summary`，放在 `details.answer` 的最後）。

歷史、哲學、通識這類答案是要點和句子的課，`<body>` 寫 `data-problems="text"`，題目的骨架照 [TEXT.md](TEXT.md)。

### 版面

- 整塊上色的只有重點（`.summary`）。定義（`.def`）上下各一條線；常見錯誤（`.trap`）是開頭有名字的普通段落，「為什麼」（`.why`）的開頭是它自己的問句；譯文（`.tr`）只在做不出翻譯圖時用。重點、定義框的每一格、常見錯誤、譯文、「這題用到」（`.uses`）和答案紙（`.sheet`）的名字由樣式加上，內文從內容寫起。
- 顏色各管一件事，不另外上色：藍是 § 編號、連結和 `<dfn>`；黃是 `.ans` 和重點框；粉紅是常見錯誤。
- 強調只有兩種，用多了就等於沒有：`.ans` 標每個算式算出來的數；`<strong>` 標一段裡讀者最該帶走的那個詞或門檻（「**n − k** 項」「**落在區間外**就拒絕」），一段最多一處。
- 公式行用 MathML，Σ 的上下限、分數、根號就會排得和講義一樣；代入行可以用 `<span class="frac">`。寫成 `<div class="formula"><math display="block">…</math></div>`：Σ 用 `<munderover><mo>∑</mo>下限<mi>n</mi></munderover>`，分數用 `<mfrac>`，ȳ 用 `<mover><mi>y</mi><mo>¯</mo></mover>`，括號寫 `<mo stretchy="false">(</mo>` 才不會被 Σ 撐高。變數用斜體（`<i>T</i><sub>41</sub>`），多個字母的縮寫（MA、CMA）用正體，公式行和代入行寫法一致。
- 查表：整張統計表、每題都要對照的規則截圖放進 `<body>` 底下的 `<aside class="panel">`，每張 `<figure data-tab="Z 表">` 一個分頁。讀者按頁眉的「查表」在對照欄打開，不用每題重貼整張表。
- 截圖只截要講的那一塊；一張圖高過一個畫面，就是截太多了。翻譯過的圖預設顯示原文，讀者按圖說的「看中文」才換成翻譯。
- 講義那部開頭寫：`<h1>`、這頁要讀多久、兩條讀法（照順序讀；趕作業先讀哪幾段再做哪幾題）、範圍表、符號小抄。題目那部開頭是速查卡，最後寫：「卡在哪就說 §編號」。其餘由 build 加上，清單在〈截圖與組頁〉。

### 截圖與組頁

截圖用 `<S>/crop.py`：先用 `find` 或 `lines` 找座標（掃描檔用 `grid`），再用 `cut` 截。每個子指令的參數、座標單位和翻譯檔的格式寫在它開頭。

```bash
CROP="uv run --no-project --with pymupdf --with pillow python <S>/crop.py"
$CROP cut 講義.pdf 4 out.png --clip 70,80,560,430 --box 90,250,540,280 --zh zh/summary.json
```

`--box` 畫紅框（要看這裡），`--mark` 塗淡黃（查表時的列與欄）。截完一定要用 Read 打開圖看一次，確認框對準了。

每張圖都放在 `<figure>` 裡，`<figcaption>` 寫出處（檔名與 `p.頁碼`）。數字從哪來要連到的圖，給 `<figure>` 一個 `id`。

頁面寫成原始 HTML，圖片用相對路徑。再用 `<S>/build.py` 組成單一檔案：

```bash
python <S>/build.py guide-src.html -o guide.html
```

build 也會內嵌圖片、加上共用樣式、替 `<h2>` / `<h3>` 編號（§1、§1.2）、把內文的「§3.2」變成連結，並產生左邊的目錄（現在讀到哪一段、讀過哪幾段、還剩多久）、頁眉（速查卡、名詞表、查表、只看重點）、每段標題下的閱讀時間和「用到這頁的題目」、對照欄、頁尾的名詞表：這些都不用自己寫。它檢查這份的結構與寫法規則，任何一條不過就不產出，並逐條印出違反哪一條、為什麼；照訊息改到通過。組好之後它用無頭瀏覽器在寬螢幕和手機寬各量一次水平溢出，有就不產出：照它列的元素，把寬的公式放進 `.formula`、寬的表格拆欄，或讓那段文字換行。寬螢幕上公式、算式、表格比正文欄寬、右邊被切掉也不產出：一條公式太寬就拆成兩行。正文太長或沒摺起來的圖太多時會印「提醒」（不擋產出）：照提醒刪減，讀者才抓得到重點。

## 答案紙：和講解分開

- 答案紙是一份要交的檔案，照老師的 Suggested Answers 格式寫：英文、簡潔，句型照講義。用 HTML 寫，再用 Chrome headless 印成 PDF（`--print-to-pdf`）。
- 所有數字都由一支計算腳本（`calc.py`）算出來：它只管算，把每個值寫成 `values.json`。答案紙寫成 `answer-tpl.html`，講解頁寫成 `guide-tpl.html`，數字用 `{{名稱}}` 佔位，用 `<S>/fill.py` 填入；`values.json` 和佔位的格式寫在它開頭。
- 答案紙每一題包成一個 `part`，講解頁用 `{{sheet:a}}` 把那一段原樣放進來，兩邊就一字不差（`fill.py --sheet`，寫法也在它開頭）。

```bash
FILL="python <S>/fill.py"
python calc.py                                                     # 寫出 values.json
$FILL values.json answer-tpl.html -o answer.html
$FILL values.json guide-tpl.html --sheet answer.html -o guide-src.html
```

- 題目本身有給、也能自己算出來的數字（例如表上已有的 MSE、F），在 `calc.py` 裡用 assert 對一次，對不上表示抄錯題。
