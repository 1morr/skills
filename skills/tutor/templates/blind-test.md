# 閉卷盲測驗收：只靠導讀頁與引用圖檔，能不能把沒看過的考題做出來

主對話派發盲測子代理（如 Opus / Pro 級）時，傳入下列路徑與考題：

```
讀 <本範本的完整路徑> 照做。
導讀頁原始檔：<guide-src.html 的完整路徑>
課件圖目錄：<slides/ 與正文引用圖檔所在目錄；僅准檢視導讀頁點名引用的圖>
考場附表：<課程發的統計表／公式表路徑；無則寫「無」>
考題：<改編自未收進導讀頁正文的課本章末題或過去考題；或模擬卷題目>
```

你是完全沒上過這門課、只拿到這份導讀頁的考生。你的任務是用考題檢驗這份導讀頁有沒有漏教先備知識、漏寫題型辨別線索、或圖表解說看圖對不起來。

## 鐵律

1. **嚴格隔離未知材料**：
   - **准讀**：`導讀頁原始檔`（`guide-src.html`）、導讀頁內 `<img src="…">` 引用的本機圖檔、導讀頁正文 `data-slide="…"` 點名指到的單頁課件原圖（如 `data-slide="L20 p.25"` 對應的 `slides/L20-25.png` 或 `.jpg`）、`考場附表`、以及本次 `考題`（含考題附圖）。
   - **禁讀**：原始課件 PDF、導讀頁未引用的課件頁、`zh.json`、`plan.md`、計算腳本（`calc.py`、`gen.py`）、答案紙與答案檔。
2. **真的看圖驗證「讀圖教學」**：遇到導讀頁講解圖表、查表或 `data-key` 必記頁，以及考題需要讀圖時，實際用讀圖工具打開對應的本機圖檔，檢查導讀頁寫的「看哪一欄、哪一條線、哪個座標」在原圖上是否真的找得到、認得出來。
3. **作答強制逐步驟標註 `§N` 依據**：
   - 先通讀導讀頁（注意 HTML 裡的 `.quiz` 點選題、`details.check` 自測、`details.answer` 摺疊題在頁面上是什麼結構），讀完後針對每一題考題完整作答。
   - **每一個推理判斷、選公式、查表與計算步驟，後面都必須標註所依據的導讀頁段落 `［依據 §N］`（或 `［依據 §N.M］`）**。
   - 如果某一步驟或某個符號在導讀頁裡根本沒教（或沒寫清楚怎麼分辨），必須靠你自己的預訓練先驗知識才推得下去，**嚴禁假裝導讀頁有教**：當場標註 **`［無依據：靠先驗猜測 — 導讀頁缺了……］`**。任何標了「無依據」的步驟都視為導讀頁驗收未過。

## 回報格式

逐項誠實回報下面四節，沒有問題的那一節寫「無」：

1. **逐題作答與 `§N` 依據鏈**：每題列出完整步驟、最終答案（寫成導讀頁教的答題格式），以及每步對應的 `［依據 §N］` 或 `［無依據：靠先驗猜測 — 原因］`。
2. **未定義先用的術語、符號或圖表欄位**：詞或符號、第一次無解釋出現的 `§`（或哪張圖的哪個座標軸／欄位沒教怎麼看）。
3. **讀兩次仍卡住或要猜的段落**：所在的 `§`、原句，以及為什麼會卡住或產生兩種讀法。
4. **零貢獻冗長段落**：讀完作答後回頭看，哪些段落既沒補先備知識、也沒幫到任何判斷或理解主線，只是在逐頁複誦過場課件。

---

## 主對話收到回報後的處置

1. 對答錯的題、任何標有 `［無依據：靠先驗猜測］` 的步驟、第 2 項未定義符號與第 3 項卡住的句子，逐一補寫或改寫導讀頁原始檔；第 4 項冗長段落收緊（純過場課件改標 `skip`），重跑 `fill.py` 與 `build.py`。
2. **失敗題重驗一次**：只要初驗有任何一題答錯或出現 `［無依據：靠先驗猜測］`，修補重組後必須**另開一個全新的盲測子代理，針對剛才失敗的題目（換一組數字或同型變體）重驗一次**，確認每一步都能乾淨標出 `［依據 §N］` 並答對，才算通過驗收。
