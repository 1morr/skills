# 照做法導讀重做：只靠這一頁，做不做得出成品

主對話驗收〈做法導讀〉時，派發子代理並傳入這幾行：

```
讀 <本範本的完整路徑> 照做。
教學頁：<導讀頁原始檔的完整路徑>
段落：<〈做法導讀〉那一段的標題；整頁都是做法頁時寫「整頁」>
數據：<原始數據在哪個檔、哪一頁>
輸出資料夾：<完整路徑>
```

你是只拿到這一頁教學與原始數據的學生。你的任務是找出這一頁哪裡教得不夠：照字面步驟做會卡住、要靠猜測、或做出來跟頁面上引用的成品不一樣的地方。

## 規則

- **只讀指定範圍**：只讀 `教學頁`（含其 `<img src>` 引用的局部截圖與 `data-slide` 點名的單頁原圖）和 `數據` 指的那一處。原始課件 PDF 的其他頁、課本、`coursework/` 下的建置腳本與成品、其他檔案一律不打開。
- **一步一步照字面做**：它叫你打什麼公式、寫哪段程式碼、點哪個選單，就照字面寫成腳本或試算表執行（存放在 `輸出資料夾`），不要用你本來就會的其他寫法繞過去。
- 那一步沒寫清楚、要靠你本來的知識猜測才做得下去時，先記下「這裡要猜」、寫明你猜了什麼，再繼續往下做。
- 全部做完才去看教學頁上引用的答案（`.sheet`），逐項核對。

## 輸出

寫成輸出資料夾裡的 `rebuild.md`（若無寫入權限則直接放在最後一則回覆）：

- **答案對照**：每個答案一列：照步驟算出來的數（多留三位小數）或輸出、頁面上寫的答案、是否一致。
- **要猜的地方**：哪一步、原文、缺了什麼、你猜了什麼、猜錯會怎樣。
- **沒先講就用到的詞或符號**：詞或符號、出現在哪一步、這一頁有沒有別處解釋（寫出標題或 `§`）。
- **說不出為什麼的步驟**：這一步叫你這樣做，但這一頁沒有說理由（也沒指回有講理由的 `§`）。
- **照字面做會錯的步驟**：公式、指令、儲存格位置、複製範圍寫錯或前後不一致的地方。
- **做出來和成品長得不一樣的地方**：照步驟做完，手上的表或輸出跟頁面上引的 `.sheet` 成品比，少了哪一欄、哪一列、哪一句結論。

每一項沒有問題就寫「無」。最後一則訊息寫 `rebuild.md` 的路徑，並用一句話總結：幾個答案一致、幾處要猜。
