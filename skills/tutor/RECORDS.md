# 學習紀錄、筆記、考前速查

tutor 做材料和批改兩個分支都寫這三個檔：做材料時照這份建和更新，批改和解答之後照這份記。`<S>` 的定義在 SKILL.md。

## 學習紀錄

`學習紀錄.md` 放在這門課的資料夾（沒有就放導讀頁旁邊），做材料和批改都寫它：

| 節 | 內容 | 什麼時候寫 |
| --- | --- | --- |
| 讀者 | 他上過課沒有、哪些前置知識不會、偏好的讀法（例如只要考前速成、一次能讀多久） | 他說了、或問問題時看得出來就記 |
| 題型 | 每份導讀頁題型表的每一列一行：題型代號（`data-type`）、導讀頁的檔名和 §、狀態、最近一次做的日期 | 做材料時加列，狀態「還沒做」；批改時更新 |
| 作業進度 | 每份作業是還沒發佈、還沒交、已交，老師答案出了沒；導讀頁、練習頁、模擬卷的檔名 | 做材料時 |
| 練習題來源 | 課本章末題、In-class Exercise、過去的測驗，哪幾題出過、出在哪一頁 | 做材料時 |
| 考試形式 | 測驗怎麼考、考場發什麼，和出處（老師的公告、過去的考卷、讀者說的） | 做材料時；讀者說了就記 |
| 術語譯名 | 每個術語第一次定下的譯名，之後都用同一個 | 做材料時 |
| 課件勘誤 | 課件上寫錯的年份、數字：檔名頁碼、課件寫的、實際的 | 做材料時 |

狀態看這個題型最近一次沒看過的完整題目，只有三種：

- 還沒做。
- 做對：沒看逐步詳解，填答格全對，給分點全拿到。
- 做過有錯：其餘都是。重做同一題才對，狀態不變。

模擬卷的結果一樣記進來。

## 筆記

`筆記.md` 放在學習紀錄旁邊，是讀者自己的東西：他錯過什麼、哪個講法讓他懂了。照導讀頁和題型分節：

```markdown
## topic5-guide.html

### seasonal-index
- 錯過（11/16 練習 1）：四個比率全部平均 → 先劃掉最高 0.86、最低 0.78，剩下的再平均；概念：看到 mean 就全部平均
- 懂了：medial mean 像評審給分，去掉最高分和最低分
```

- `##` 寫導讀頁的檔名，`###` 寫題型代號（題型表的 `data-type`）。檔案裡其他標題底下的東西是讀者自己寫的，原樣留著。
- 一條記一件事，用讀者當時的數字和他自己的話：「錯過」寫錯成什麼 → 對的是什麼，分號後面接錯因（COACH.md〈批改〉表上的四種之一）和帶他錯的線索，批改時沒分錯因的只寫到箭頭那一段；「懂了」寫讓他懂的那個講法。
- 只記發生過的事：批改出來的錯、他問過的問題。課件的重點在速查卡上，筆記留給他自己的東西。

## 考前速查

`review.html` 放在導讀頁旁邊：每份導讀頁的速查卡照課程的順序排成一頁，題型下面接筆記。速查卡來自考點清單，所以重點不會漏；筆記是讀者自己的話，所以好記。筆記多了一條，或多了一份導讀頁，就重組：

```bash
python <S>/review.py topic1-guide.html topic2-guide.html --notes 筆記.md --title "<課名> 考前速查" -o review.html
```

它印「提醒」時照訊息改筆記（多半是題型代號寫錯）。讀者說要考前複習時，給他這一頁的完整路徑，再把「做過有錯」的題型列給他。
