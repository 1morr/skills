# 翻譯課件上的字

你拿到一份 `zh.json`：鍵是課件上的每一塊原文，照課件的順序排；值是要你填的譯文。填好的譯文會蓋掉原文、寫回課件圖上同一個位置，給正在準備考試的學生對照著讀。

逐塊填上讀者的語言（交代你的人會說是哪一種；沒說就用繁體中文）：

- **術語和專有名詞每次都寫成「譯名（原文）」**：例如「族群民族主義（ethnic nationalism）」「南進（Nam tiến）」。同一個詞出現幾次就寫幾次，每一塊都帶著原文：考卷印的是原文，讀者要在每一頁都對得上。
- **譯名照術語表**：交代裡附的術語譯名，原文怎麼對、你就怎麼寫；表上沒有的自己定，同一個詞從頭到尾同一個譯名。
- **其餘的字求短**：譯文要塞回原來那一塊的位置，太長字會縮小。帶了原文之後更擠，所以術語以外的字用最短的講法：標題用短語，條列不加原文沒有的話。
- **拆開的句子接得上**：課件上一句話換行後常被拆成相鄰的兩塊。先把整句譯好，再照中文的語序分到這兩塊，兩塊連著讀是一句通順的話。
- **原文的記號照留**：條列開頭的 ➤、•、數字編號，括號、引號、箭頭。
- 軟體輸出的欄名和列名（Source、DF、SS）、統計表的表頭也要翻，後面括號留原文：考卷上印的是原文。
- 值是 HTML：原文是粗體的詞用 `<b>`。

這幾種留空字串，那一塊就保持原文：

- 沒有通行譯名的人名、書名的原文、機構縮寫（UMNO、ASEAN）。
- 地圖和圖表上的地名、座標軸的數字、年份、頁碼。
- 公式、變數、單位。
- 已經是讀者的語言的字。

人名、朝代、地名有通行的譯名時也寫成「譯名（原文）」；拿不準通行譯名是什麼就只留原文，不要自己音譯。

直接改 `zh.json`，保持合法的 JSON，鍵一個字都不動、不增不減。

完成條件：每個鍵都看過，值是譯文，或是你判斷過不翻而留的空字串。回報三樣：譯了幾塊、留空幾塊；術語表上沒有、這次新定的譯名（原文 → 譯名）；拿不準的詞和你怎麼處理。
