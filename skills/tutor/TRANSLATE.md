# 翻譯課件上的字

你拿到一份 `zh.json`：鍵是課件上的每一塊原文，照課件的順序排；值是要你填的譯文。填好的譯文會由 `build.py` 渲染成右欄每張課件原圖下方的 HTML 譯文對照層（`.deck-zh`），給正在準備考試的學生對照原圖閱讀。

逐塊填上讀者的語言（交代你的人會說是哪一種；沒說就用繁體中文）：

- **術語和專有名詞保留「譯名（原文）」**：例如「族群民族主義（ethnic nationalism）」「南進（Nam tiến）」。考卷印的是原文，讀者在看某一頁課件譯文時要能直接對回圖上的英文詞。
- **譯名照術語表**：交代裡附的術語譯名，原文怎麼對、你就怎麼寫；表上沒有的自己定，同一個詞從頭到尾同一個譯名。
- **精練直白**：標題用短語，條列不加原文沒有的解釋。
- **拆開的句子接得上**：課件上一句話換行後常被拆成相鄰的兩塊。先把整句譯好，再照中文的語序分到這兩塊，兩塊連著讀是一句通順的話。每一塊只放它自己那一段的意思：同一塊原文在別頁再出現時用的是同一個譯文，併了鄰居的字進來，那一頁就會多出一段。
- **照課件翻**：課件上的年份、數字看起來寫錯了也照它寫，在回報裡列出來，由交代你的人在正文更正。
- **原文的記號與公式照留**：條列開頭的 ➤、•、數字編號，括號、引號、箭頭。**一塊裡標籤文字和公式／符號混在一起時，照常翻譯文字並保留公式符號**（譯文排在原圖下方的 HTML 區塊，不會蓋掉原圖上的公式）。
- 軟體或程式輸出的欄名和列名（Source、DF、SS）、統計表的表頭也要翻，後面括號留原文：考卷上印的是原文。
- 值是 HTML：原文是粗體的詞用 `<b>`。

這幾種留空字串，那一塊就不重複列進譯文層：

- 沒有通行譯名的人名、書名的原文、機構縮寫（UMNO、ASEAN）。
- 地圖和圖表上的純地名標籤、座標軸刻度、純年份、頁碼。
- 只有純公式、變數或單位、完全沒有說明文字的塊。
- 已經是讀者的語言的字。

人名、朝代、地名有通行的譯名時也寫成「譯名（原文）」；拿不準通行譯名是什麼就只留原文，不要自己音譯。

直接改 `zh.json`，保持合法的 JSON，鍵一個字都不動、不增不減。

完成條件：每個鍵都看過，值是譯文，或是你判斷過不翻而留的空字串。回報四樣：譯了幾塊、留空幾塊；術語表上沒有、這次新定的譯名（原文 → 譯名）；拿不準的詞和你怎麼處理；課件上看起來寫錯的地方。
