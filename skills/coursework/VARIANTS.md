# 多版本探索與比較

`coursework` 的選配分支：只有在開放式／視覺設計作業（海報、簡報、開放式報告），或需要比較外部現成版本（隊友草稿、舊版）時才讀這份。一般有固定做法的作業直接照 SKILL.md 做一版，不讀這份。`<T>` 的定義在 SKILL.md。

## 前置條件

- **先盲讀再探索**：一定在 SKILL.md〈盲讀〉完成、`coursework/讀法.md` 由使用者拍板之後，才進這個分支。
- **隔離與封存**：既有舊成品維持封存；外部現成版本收到獨立資料夾，不給自製新版的子代理看到。

## 路徑一：輕量方向探索（預設）

適用：開放式報告、海報、簡報等還沒定結構或版面骨架的作業。先用低成本把方向談定，再做一版完整成品。

1. 在 `coursework/options/` 底下產出 2–3 份低保真方案（`opt1.md`..`opt3.md` 或簡版線框圖）：寫出結構骨架、視覺分區或論點順序、各自對應的評分重點與取捨。
2. 給使用者一張方案對照表，向使用者提問（有互動提問工具就用它，否則在對話列點詢問）請他選定方向，或指定要合併哪幾項優點。
3. 方向記進 `coursework/紀錄.md`，回到 SKILL.md〈計畫〉與〈製作〉，只做定案那一版完整成品。

完成條件：`coursework/options/` 有 2–3 份方案；使用者選定的方向已記進 `coursework/紀錄.md`。

## 路徑二：獨立完整版比較（升級路徑）

只在兩種情況升級做完整多版：真實內容密度決定版面是否成立（例如海報圖文塞不塞得下、長表配比要排出來才看得出好壞），或要比較多個外部現成版本（隊友草稿、不同工具做的成品）。不開 git worktree，只靠資料夾隔離與不讀清單。

### 準備各版

- **自製多版**：建 `coursework/variants/v1/`..`vN/`（預設 2–3 版）。平行開高階推理子代理（如 Opus / Pro 級）各自獨立做：每個子代理只拿到老師的原檔、複製到暫存目錄的 `讀法.md`、共同任務要求，以及它自己的輸出資料夾；「不讀的路徑清單」包含整個 `coursework/`（含其他 `variants/`）與封存的舊成品，確保各版互不相見。
- **外部版本**：原樣放進 `coursework/variants/ext-<名稱>/`（zip 先解壓），不開製作子代理；若同時有自製版，外部版本一併列入不讀清單。
- **只比外部版本**：`讀法.md` 拍板後直接進〈審查與選版〉，不開製作子代理。

完成條件：每個版本的產出都在各自的 `coursework/variants/<版名>/` 裡，且能直接打開或渲染；自製版沒有讀到其他版本或舊成品。

### 審查與選版

審的是使用者實際會看到的樣子。

1. **先定評分項，再看任何一版**：從老師的原檔與 `讀法.md` 列出評分項寫進 `coursework/紀錄.md`。在打開任何一版的產出之前定案，免得看完後替偏好的那版找理由。
2. **渲染每一版**：PDF 轉逐頁圖、HTML 用瀏覽器自動化工具照實際尺寸截圖、程式實際跑起來；全圖與局部放大存到 `coursework/variants/review/<版名>/`。
3. **逐項打分**：每個評分項、每一版給「做到 / 有問題」，有問題的附位置與截圖。使用者事前提過偏好的，正面回應並對照評分項說明同不同意。
4. **選基礎版與列 cherry-pick 項目**：
   - 選結構和根本做法最好（事後最難改）的那一版當基礎版。若每一版都有關鍵評分項沒做到、且補起來等於重做，結論是**都不夠好**，說明各版卡在哪以及重做要調什麼，不勉強選。
   - 只列比基礎版好的改善項：來源（版名、檔案與位置）、好在哪裡、搬進來會撞到什麼。
5. **向使用者確認**：依序給出各版產出與截圖完整路徑、建議的基礎版（對照評分項）、基礎版還要改的地方、建議 cherry-pick 清單、每版一句總評；向使用者提問（有互動提問工具就用它，否則在對話列點詢問）確認選哪一版與要合進哪幾項。
6. **定版接入主流程**：把選定基礎版與核可的 cherry-pick 項目整合到 `coursework/src/` 與 `coursework/out/`，寫進 `紀錄.md`，再接回 SKILL.md〈驗證〉與〈教學〉。

完成條件：評分項在看產出前已記進 `紀錄.md`；每個評分項在每一版都有「做到 / 有問題」與證據；使用者已選定基礎版（或決定重跑），定版產出已放到 `coursework/out/`。

## 開放式報告／海報的盲做調整

回到 SKILL.md〈驗證〉跑 `<T>/redo.md` 時，開放式報告、海報、簡報沒有單一標準答案，盲做不追求逐字重現：請盲做子代理獨立產出**結構骨架、核心論點／視覺分區與必含要素清單**（涉及數據計算的段落仍獨立重算）。對比時檢查成品有沒有漏掉評分重點、論證跳步或數據矛盾，不比文句是否一致。
