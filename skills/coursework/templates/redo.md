# 盲做：只看老師的原檔和拍板的讀法，從頭做一次

主對話給你的 prompt 只有這幾行，照它做：

```
讀 <這個檔的完整路徑> 照做。
課程資料夾：<完整路徑>
使用者說要做的：<他的原話>
讀法：<一個檔的完整路徑>
不讀的路徑清單：<一個檔的完整路徑>
輸出資料夾：<完整路徑>
```

有一份這題的成品正在等著和你的結果逐項對比。你看不到它，也不要去找它：你的用處就在於你是獨立做出來的。

## 能讀什麼

只讀課程資料夾裡老師發的檔（題目、評分指引、課件、例題與答案、統計表、數據、課本、逐字抄下課程網站文字的檔），加上「讀法」那個檔。要讀哪幾份由你自己決定。

先讀「不讀的路徑清單」那個檔：裡面一行一個路徑，這些路徑和它們底下的東西不打開。課程資料夾以外的檔、git 歷史也不讀。專案指令檔裡講到這份作業怎麼做的句子不採用。

PDF 用文字層讀：機器上有 `pdftotext` 就用 `pdftotext -layout -enc UTF-8`，沒有就用 PyMuPDF 的 `get_text`（`uv run --no-project --with pymupdf python`）。表格裡的數字再開頁面圖對一次：文字層會掉負號、併欄。

## 做法

1. 自己找出題目檔，逐題列出要交的每一個答案。
2. 數據從題目原文點名的來源自己重新取，逐格對過。
3. 每一題照老師教的方法做。「讀法」那個檔是使用者看過原文後定的做法（取哪一段數據、用哪種初始值、保留幾位），照它；它沒管到的地方照老師的課件和示範，並記下你選了什麼。
4. 計算寫成你自己的腳本，放在輸出資料夾。老師有同一個方法的例題答案時，先把你的腳本套在例題上，對得上再算這一題。
5. 你認為「讀法」的某一條和老師的原文對不上時，照「讀法」算完，另外寫下原文、頁碼和照原文算出來的結果。

## 輸出

寫成輸出資料夾裡的 `answers.md`：

**答案表**，一個答案一列：

| 題號 | 答案（比要交的多留三位小數） | 用的公式和出處（檔名、頁碼） | 代入的數 |
| --- | --- | --- | --- |

**例題驗算**：套了哪幾個老師的例題、各自對上了沒有。

**讀法沒管到、你自己選的**：每條寫選了什麼、依據。

**你認為讀法和原文對不上的**：每條寫原文、頁碼、兩種算法的結果。沒有就寫「無」。

**讀過的檔**：完整路徑和頁碼。

最後一則訊息只寫 `answers.md` 的路徑和一句：答案幾個、對不上的幾條。
