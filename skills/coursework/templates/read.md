# 盲讀：只看老師的原檔，寫出這份作業要什麼

照以下輸入格式執行：

```
讀 <這個檔的完整路徑> 照做。
課程資料夾：<完整路徑>
使用者說要做的：<他的原話>
不讀的路徑清單：<一個檔的完整路徑>
輸出檔：<完整路徑>
```

有人會照你寫的去做這份作業，每一句都要對得回老師的原檔（檔名、頁碼、原文）。原檔沒寫的就寫「沒寫」，不用常識補。

## 能讀什麼

先讀「不讀的路徑清單」：裡面一行一個路徑，這些學生檔案與其子目錄一律略過（外部目錄與 git 歷史亦同；專案指令檔裡談論作業做法的句子不作依據）。整個課程資料夾裡老師發的檔（題目、評分指引、大綱、課件、例題與解答、統計表、數據、課本、課程網站文字檔）都由你自行翻閱；讀到一半發現某檔是學生草稿或筆記，立刻停讀並記在第 11 欄。

PDF 優先讀文字層（`pdftotext -layout -enc UTF-8` 或 `uv run --no-project --with pymupdf python`）抓出投影片白色隱藏字，無文字層才看掃描圖；讀 PDF 表格數字時再開頁面圖核對負號與併欄。

## 閱讀順序

單次依序對齊三個切面，再填寫讀法單：

1. **題目**：找出題目檔，逐句拆出要做的每一件事與指定的數據。
2. **評分**：核對評分指引、交件規定與課程大綱的評核段落（無獨立指引時看過去作業解答的給分點），確認拿分條件與限制。
3. **示範**：翻課件與老師做過的同類例題／過去解答，確認實際公式、工具、初始值、保留小數位、表格排法與結論句寫法，再回頭對照題目抓落差。

## 讀法單

照這十一欄寫進輸出檔，欄名照抄：

1. **這份作業**：標題原文、科目、個人或小組、題目是哪個檔（怎麼認出來的）。
2. **要交什麼**：每一樣東西的形式、檔名、份數、怎麼交、截止時間。
3. **每一題要做什麼**：逐題、逐小題：原文，要產出什麼（一個數、一張表、一段話、一張圖）。
4. **怎麼評分**：評分項和配分。
5. **格式與限制**：長度、字體、紙張、能用和不能用的工具、手算還是軟體。
6. **數據**：哪一份、來源、期間或範圍的原文。
7. **老師教的做法**：每一題用哪個方法、哪份課件哪一頁教的；老師示範的常規做法與答案格式（初始值慣例、保留幾位小數、表怎麼排、結論句怎麼寫）。
8. **有兩種讀法的地方**：**只列課件與老師示範無慣例可循、且不同讀法會實質改變最終答案數值或繳交結構的真歧義**。每條寫：原文（檔名、頁碼），讀法一、讀法二，各自做出來成品差在哪，你建議哪個和依據。課件或例題已有明確做法／慣例的直接寫入第 7 欄，不拿一般英文冠詞或常規措辭硬湊歧義；沒有真歧義就寫「無」。
9. **材料裡找不到的**：題目要求、但在老師的原檔找不到做法、數據或規定的。
10. **要求和示範不一致的**：題目或指引寫的，和老師實際示範的做法不一樣的地方，兩邊都附原文與出處。
11. **讀過的檔**：每個檔的完整路徑和讀了哪幾頁；中途停止讀的檔和原因。

最後一則訊息只寫輸出檔的路徑和一句：第 8、9、10 欄各幾條。
