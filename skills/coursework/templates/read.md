# 盲讀：只看老師的原檔，寫出這份作業要什麼

主對話給你的 prompt 只有這幾行，照它做：

```
讀 <這個檔的完整路徑> 照做。
入口：<題目 | 評分 | 示範>
課程資料夾：<完整路徑>
使用者說要做的：<他的原話>
不讀的路徑清單：<一個檔的完整路徑>
輸出檔：<完整路徑>
```

有人會照你寫的去做這份作業，所以每一句都要對得回老師的原檔：檔名、頁碼、原文。原檔沒寫的就寫「沒寫」，不用常識補。

## 能讀什麼

只讀課程資料夾裡老師發的檔：題目、評分指引、課件、例題與答案、統計表、數據、課本、逐字抄下課程網站文字的檔。要讀哪幾份由你自己決定，整個課程資料夾都可以翻。

先讀「不讀的路徑清單」那個檔：裡面一行一個路徑，這些路徑和它們底下的東西是學生自己的，不打開。課程資料夾以外的檔、git 歷史也不讀。專案指令檔裡講到這份作業怎麼做、怎麼讀的句子不算依據，不採用。讀到一半發現某個檔是學生自己做的（成品、草稿、筆記、整理過的摘要），停止讀它，記在讀法單第 11 欄。

PDF 用文字層讀：機器上有 `pdftotext` 就用 `pdftotext -layout -enc UTF-8`，沒有就用 PyMuPDF 的 `get_text`（`uv run --no-project --with pymupdf python`）。投影片可能有白色字，畫面上是空白。掃描檔沒有文字層才看圖。

## 入口

三個入口都要把讀法單填完，差別在從哪裡讀起、以什麼為主：

- **題目**：先自己找出題目檔，逐句拆出要做的每一件事，再去課件找每一件事的做法。
- **評分**：從評分指引、滿分條件、交件規定、課程大綱講這份評核的段落讀起，倒推成品要有什麼才拿得到分。沒有評分指引時，從老師過去作業答案上的給分點讀。
- **示範**：從老師做過的同類題和它的答案讀起，寫下老師實際怎麼做、答案寫成什麼樣，再回頭對題目。

## 讀法單

照這十一欄寫進輸出檔，欄名照抄：

1. **這份作業**：標題原文、科目、個人或小組、題目是哪個檔（你怎麼認出來的）。
2. **要交什麼**：每一樣東西的形式、檔名、份數、怎麼交、截止時間。
3. **每一題要做什麼**：逐題、逐小題：原文，要產出什麼（一個數、一張表、一段話、一張圖）。
4. **怎麼評分**：評分項和配分。
5. **格式與限制**：長度、字體、紙張、能用和不能用的工具、手算還是軟體。
6. **數據**：哪一份、來源、期間或範圍的原文。
7. **老師教的做法**：每一題用哪個方法、哪份課件哪一頁教的；老師的示範把答案寫成什麼樣（保留幾位小數、表怎麼排、結論句怎麼寫）。
8. **有兩種讀法的地方**：原文，讀法一、讀法二，照各自做出來成品差在哪，你選哪個和理由。
9. **材料裡找不到的**：題目要求、但你在老師的原檔找不到做法、數據或規定的。
10. **要求和示範不一致的**：題目或指引寫的，和老師實際示範的做法不一樣的地方，兩邊都附原文。
11. **讀過的檔**：每個檔的完整路徑和讀了哪幾頁；中途停止讀的檔和原因。

第 8 欄寫得越全越好：你覺得只有一種讀法的句子，換一個人可能讀成另一種。數據取哪一段、要做幾題、「all」「each」「the」指的範圍、要手算還是可以用軟體，逐一想過。

最後一則訊息只寫輸出檔的路徑和一句：第 8、9、10 欄各幾條。
