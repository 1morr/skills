# 定位：這份作業是哪些檔

照以下輸入格式執行：

```
讀 <這個檔的完整路徑> 照做。
課程資料夾：<完整路徑>
使用者說要做的：<他的原話>
輸出檔：<完整路徑>
```

你只找檔、抄檔上的原文與核對期間，不替題目定做法。只讀課程資料夾內的檔，忽略外部檔案與 git 歷史。PDF 讀文字層（`pdftotext -layout -enc UTF-8` 或 `uv run --no-project --with pymupdf python`），留意投影片白色字。

在課程資料夾裡找出和「使用者說要做的」有關的每一個檔，寫進輸出檔：

1. **題目的候選**：每個可能是這份作業題目的檔一列：完整路徑、大小、修改日期、首頁標題原文、檔內寫的日期（截止日、學年）。有兩個以上全列，不自行挑。
2. **評分指引和交件規定的候選**：同上欄位；課程大綱裡講這份評核的那一段也抄出原文和頁碼。
3. **老師的示範的候選**：老師做過的同類題與答案（例題解答、課堂練習、過去作業解答）。
4. **數據**：抄出題目點名數據的原文與頁碼，核對資料夾裡哪個檔吻合；列該檔大小、列數或頁數、實際涵蓋期間。期間對不上或有兩個相近檔時照實寫。
5. **名字相近的其他檔**：別的年份、別的版本、編號相鄰的作業，各寫一列說明與候選差在哪。
6. **不是老師發的檔**：看起來是學生自己做的東西（成品、草稿、筆記、腳本、紀錄），只憑檔名、大小、日期列出，不讀內容。

最後一則訊息只寫輸出檔路徑和一句：題目的候選有幾個。
