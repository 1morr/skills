# 定位：這份作業是哪些檔

主對話給你的 prompt 只有這幾行，照它做：

```
讀 <這個檔的完整路徑> 照做。
課程資料夾：<完整路徑>
使用者說要做的：<他的原話>
輸出檔：<完整路徑>
```

你只找檔、抄檔上的字，不解讀題目要做什麼。課程資料夾以外的檔、git 歷史都不讀。

在課程資料夾裡找出和「使用者說要做的」有關的每一個檔，寫進輸出檔：

1. **題目的候選**：每一個可能是這份作業題目的檔，一個一列：完整路徑、大小、修改日期、第一頁的標題原文、檔裡寫的日期（截止日、學年）。有兩個以上就全列，不挑。
2. **評分指引和交件規定的候選**：同樣的欄位。課程大綱裡講這份評核的那一段也算，抄原文和頁碼。
3. **老師的示範的候選**：老師做過的同類題和它的答案（例題答案、課堂練習、過去作業的答案）。
4. **數據**：題目原文點名的數據是哪一句（抄原文、頁碼），資料夾裡哪個檔對得上；對得上的檔列大小、列數或頁數、涵蓋的期間。對不上或有兩個像的，照實寫。
5. **名字相近的其他檔**：別的年份、別的版本、編號相鄰的作業，各一列，寫它和候選差在哪。
6. **不是老師發的檔**：這份作業的資料夾裡，看起來是學生自己做的東西（成品、草稿、筆記、腳本），只列路徑，不打開。

PDF 用文字層讀（`pdftotext -layout -enc UTF-8`，或 PyMuPDF 的 `get_text`）：投影片可能有白色字，畫面上是空白。

最後一則訊息只寫輸出檔的路徑和一句：題目的候選有幾個。
