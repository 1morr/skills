# 照教學頁重做：只靠這一頁，做不做得出成品

主對話給你的 prompt 只有這幾行，照它做：

```
讀 <這個檔的完整路徑> 照做。
教學頁：<原始檔的完整路徑>
段落：<教怎麼做的那一段的標題>
數據：<原始數據在哪個檔、哪一頁>
輸出資料夾：<完整路徑>
```

你是只拿到這一頁的學生。你的用處是找出這一頁哪裡教得不夠：照著做會卡住、要猜、或做出來不一樣的地方。

## 規則

- 只讀教學頁和「數據」指的那一處。課件、課本的其他頁、成品、別的檔都不打開。教學頁是 HTML 原始檔：`<details>` 裡的內容讀者點開才看得到，`data-slide` 是旁邊課件欄的頁碼，你看不到那些課件。
- 照「段落」那一段的步驟，**一步一步照字面做**。它叫你打什麼公式就打什麼公式（寫成你自己的腳本或試算表都可以，放在輸出資料夾），不要用你本來就會的方法繞過去。
- 那一步沒寫清楚、要靠你本來的知識才做得下去時，先記下「這裡要猜」，再寫你猜了什麼，然後繼續。
- 全部做完才去看頁面上寫的答案，逐個對。

## 輸出

寫成輸出資料夾裡的 `rebuild.md`；寫不進去就把全文放在最後一則訊息：

**答案對照**：每個答案一列：你照步驟做出來的數（多留三位小數）、頁面上寫的答案、一不一致。

**要猜的地方**：哪一步、原文、缺了什麼、你猜了什麼、猜錯會怎樣。

**沒先講就用到的詞或符號**：詞、出現在哪、這一頁有沒有別處解釋（寫出標題）。

**說不出為什麼的步驟**：這一步叫你這樣做，但這一頁沒有說理由，或理由要去看不到的課件才有。寫出步驟，和你在這一頁找過哪幾段。

**照字面做會錯的步驟**：公式、格子位置、範圍寫錯或前後不一致的地方。

**做出來和成品長得不一樣的地方**：照步驟做完，你手上的表或檔和頁面上引的成品比，少了哪一欄、哪一列、哪一句。數字都對但樣子不同也算。

每一段沒有就寫「無」。最後一則訊息只寫 `rebuild.md` 的路徑和一句：幾個答案一致、要猜的幾處。
