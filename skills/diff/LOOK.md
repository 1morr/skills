# 外觀

這頁是**校樣**：讀者拿它對照兩版，找出每一處改動，判斷改得對不對。內容是主角，介面退到邊上。每一頁照內容重新排版，但 token、字體和標記方式每頁都一樣，讀者換一頁不必重新學怎麼讀。

## 原則

- **文件長得像文件**：文件頁的內文用書本排版（襯線字、70ch 行寬）；程式頁像工程簡報，只有程式碼、指令和輸出用等寬字。
- **改動跳出來，沒改的退後**：每處改動同時有底色、刪除線或底線、頁邊的**修訂條**（change bar，印刷校樣的慣例）三種標記，少了任何一種，讀者照樣分得出刪和加。
- **強度給最小的單位**：段內改的幾個字標得最濃；整段新增或刪除用淡一級的底色，否則一大片紅綠會蓋過真正要看的字。
- **切換不跳位**：切換並排／合併、只看改動時，讀者正在看的那處改動停在畫面上同一個位置。切換前用目前選中的改動當錨點（不在畫面內才改找畫面上第一處），記下 `getBoundingClientRect().top`，重畫後再捲回去。

## Token

整頁的顏色只從這組變數取，不另寫色碼；深色模式跟著 `prefers-color-scheme`。

```css
:root {
  color-scheme: light dark;
  --paper: oklch(0.985 0.004 85);   --panel: oklch(0.962 0.006 85);   --rule: oklch(0.88 0.008 85);
  --ink: oklch(0.25 0.012 260);     --ink-2: oklch(0.47 0.012 260);   --accent: oklch(0.5 0.15 255);
  --del-bg: oklch(0.93 0.045 25);   --del-ink: oklch(0.44 0.16 25);   --del-bar: oklch(0.62 0.19 25);
  --ins-bg: oklch(0.93 0.055 165);  --ins-ink: oklch(0.38 0.1 165);   --ins-bar: oklch(0.6 0.13 165);
  --note-bg: oklch(0.955 0.04 85);  --note-ink: oklch(0.4 0.07 70);   --note-bar: oklch(0.72 0.13 75);
}
@media (prefers-color-scheme: dark) { :root {
  --paper: oklch(0.2 0.012 260);    --panel: oklch(0.235 0.014 260);  --rule: oklch(0.34 0.014 260);
  --ink: oklch(0.92 0.008 85);      --ink-2: oklch(0.72 0.01 260);    --accent: oklch(0.75 0.12 255);
  --del-bg: oklch(0.33 0.06 25);    --del-ink: oklch(0.86 0.08 25);   --del-bar: oklch(0.66 0.17 25);
  --ins-bg: oklch(0.33 0.05 165);   --ins-ink: oklch(0.88 0.08 165);  --ins-bar: oklch(0.66 0.13 165);
  --note-bg: oklch(0.27 0.025 80);  --note-ink: oklch(0.86 0.06 85);  --note-bar: oklch(0.74 0.12 80);
} }
```

- 整段新增或刪除的底色：`color-mix(in oklch, var(--del-bg) 60%, var(--paper))`（新增同理）。
- `--accent` 只用在可以操作的東西上：選中的切換、焦點環、連結、滑桿。`::selection`、`caret-color`、`accent-color`、`scrollbar-color` 和 `:focus-visible` 也從這組取色。

## 字體

只用系統字，離線也能顯示。Latin 字族排在 CJK 前面，英文和數字才會用 Latin 字形。

```css
--font-ui:   system-ui, -apple-system, "Segoe UI", "PingFang TC", "Noto Sans TC", "Microsoft JhengHei", sans-serif;
--font-doc:  "Iowan Old Style", "Palatino Linotype", Palatino, Georgia, "Songti TC", "Noto Serif TC", "PMingLiU", serif;
--font-code: ui-monospace, "SF Mono", Menlo, Consolas, "Noto Sans Mono CJK TC", monospace;
```

- 文件內文用 `--font-doc`，工具列、標籤、說明和計數用 `--font-ui`。原文件是無襯線的（簡報、海報），內文也改用 `--font-ui`。
- 字級固定用 rem：內文 1.0625rem、行高 1.7；說明與標籤 0.875rem，不再更小；段落標題 1.375rem、頁面標題 2rem（手機 1.625rem）；摘要或結論段 1.125–1.25rem。
- 計數、行號和數字欄加 `font-variant-numeric: tabular-nums`；`html` 加 `text-autospace: normal`。
- 次要文字用 `--ink-2` 加上較小的字級來區分，正體字。

## 標記改動

- 刪除：`<del>`，`--del-bg` 底、`--del-ink` 字、1px 刪除線。新增：`<ins>`，`--ins-bg` 底、`--ins-ink` 字、底線（`text-underline-offset: .2em`）。圓角 2px，加上 `box-decoration-break: clone`。
- 標記兩端的空白移到標籤外面，底線和底色才會剛好包住字。
- 連續的刪除段和新增段（整段改寫）合成**一組**：所有刪除段放進同一塊 `.run-del`，新增段放進同一塊 `.run-ins`，塊內段落之間不留色縫；並排時左欄放刪除、右欄放新增。整段刪除的刪除線用半透明的 `--del-ink`，原文才讀得出來。
- **修訂條**掛在每一塊改動本身（`.run` 與改寫過的段落各用一個 `::before`）：寬 3px、放在左側頁邊；刪除用 `--del-bar`，新增用 `--ins-bar`，段內改寫用 `--ink-2`；目前選中的那處加寬到 5px。
- 讀屏器：塊的開頭放一段 visually-hidden 文字「以下整段刪除」；`del::before` / `ins::before` 用隱藏文字讀出「刪除」「新增」。

## 版面

- **並排**：每一組改動或沒改的段落各佔一列 grid（`1fr 1fr`，欄距 4rem），左右兩欄等高對齊，中間不畫分隔線。欄頭（兩版的標籤）用 sticky 貼在工具列下方，往左右各延伸 1.5rem，蓋住捲上來的修訂條。
- **合併**：單欄 72ch 置中，同一段裡 `<del>` 緊接著 `<ins>`；「⋯ n 段沒有改動」那條分隔列也照這個寬度。
- **工具列**：實心 `--paper` 底、sticky 貼頂。並排／合併做成一組 segmented control（`aria-pressed`），只看改動用開關；右側是上一處／下一處、「第 n / N 處」，鍵盤 `j` / `k`。
- **只看改動**：連續沒改的段落收成一條虛線分隔列，可以點開；每處改動的前後各留一段當上下文。
- **PDF**：抽出來的文字塊大約一行一塊，段距收到 0.1rem，讀起來才像連續的文字；改動前後另外多留一點空間。
- **窄螢幕**（< 760px）：並排的每一列改成上下疊放，各帶一個小標籤「前 · 版本名」「後 · 版本名」，沒改的列只顯示一次；工具列維持一行，上一處／下一處移到右下角的浮動膠囊（`body` 底部留出它的高度）。sticky 工具列不要加 `backdrop-filter`，它會讓裡面的 `position: fixed` 改以工具列為準。表格和程式碼在自己的容器裡橫向捲動。

## 說明與標籤

- 說明放在它那處改動的正下方，並排時放在後版那一欄：`--note-bg` 底、`--note-ink` 字、`--font-ui` 0.875rem、圓角 4px，依序是一個「註」字、tag、說明文字。
- `tag` 是文字標籤，細外框加字，例如「必須修」。「推斷」用虛線外框，一看就知道是暫定的；程式頁的推斷句也用同一個樣式。

## 表格

- 照原文件的結構畫：細格線，第一列 `--panel` 底、字重 600，儲存格 `min-width: 4.5em`，避免中文窄欄一字一行。
- 改過的格子：格內照段內規則標記，右上角放一個 8px 的 `--note-bar` 三角形。數字、日期這類短格子整格替換（前值刪除、後值新增），不要逐字拆成碎片。
- 新增列：整列 `--ins-bg`；刪除列：`--del-bg` 加刪除線。兩種列最左邊都有一欄窄記號欄（`+` / `−`），放在頁邊（表格容器往左縮進同寬），格內放原文、不再逐字標記。
- `columns` 裡是 `null` 的整欄：表格上方標「新欄」或「已刪欄」，整欄鋪同色底；新欄只畫在後版，已刪欄只畫在前版，合併檢視兩種都畫。

## 渲染圖對照

- 兩版用同一個方法轉圖，裁成**同一個框**：取兩版內容範圍的聯集，四周留邊，頁面下方的大片空白不要截進來。
- 兩張圖等寬並排，上方各一行標籤（版本 · 頁碼）。圖放在 `--panel` 襯底上，外框 1px `--rule`，加柔和陰影（`0 1px 2px` 疊 `0 8px 24px`，透明度 8%）；深色模式下圖片加 `filter: brightness(.9)`，不反轉顏色。
- 尺寸相同就加對照滑桿：兩張圖疊在同一框裡，上層用 `clip-path: inset(0 0 0 X%)` 跟著 `<input type="range">` 移動；分界線用 `--accent`，中間一個把手，滑桿兩端標「前」「後」。
- 兩版像素相同的頁收成一行「第 n 頁兩版像素相同」，圖放進 `<details>`。點圖用 `<dialog>` 放大，點一下或按 Esc 關閉。

## 程式頁

- 寬螢幕：左邊一條 sticky 目錄，用 IntersectionObserver 標出目前的段落；右邊的文字欄 70ch，證據和 diff 可以伸到整欄寬。1000px 以下拿掉目錄。
- 頁首：標題，下面一行 meta：`base..head` 短 SHA（等寬字）、分支、檔案數加 `+n −m`、證據等級。摘要緊接在下面，字級 1.25rem。
- 「為什麼」引用原文放在 `--panel` 底的 blockquote 裡；來源寫成小的等寬外框標籤，例如 `5fca937 message`。
- 示意圖是 `--panel` 底的等寬區塊（呼叫樹、檔案樹），新增的部分用 ins 的顏色，原有的部分用 `--ink-2`；加上 `role="img"` 和一句 `aria-label`。
- **合併風險**用一個詞定調：「雙向門」是 `--ink` 字加細外框，「單向門」是 `--del-ink` 字加同色外框，後面接一句理由，再列影響範圍。
- **決定**用定義清單：`<dt>` 寫選擇，`<dd>` 寫理由和來源，替代方案用 `--ink-2` 另起一行。
- **證據**：前後兩個面板並排，窄螢幕改成上下疊。面板標頭寫「修改前 · SHA」和結果（例如「12 條 FAIL · exit 1」，用 del／ins 字色）。輸出用 `pre-wrap` 換行，加懸掛縮排，不用橫向捲動藏住內容；失敗的行鋪 `--del-bg`，到了修改後通過的同一條鋪 `--ins-bg`，`…` 用 `--ink-2`。
- **關鍵 diff**：每段上方一句話說明，下方是 unified 格式：舊行號、新行號、記號欄、程式碼；新增或刪除的行整行鋪底，記號用 `--ins-bar` / `--del-bar`。新檔整段都是 `+`，所以只在記號欄和標題（「新檔」標籤）標出來，內容維持一般樣式。省略的地方放一行 `⋯`。
- **檔案表**：路徑用等寬字，目錄部分 `--ink-2`，斜線後面加 `<wbr>`；`+n −m` 用 ins／del 字色。窄螢幕改成每檔兩行：第一行是路徑和增減，第二行是說明。
- **親自試**：有序清單，每一步的指令放在 `--panel` 底、可以選取的等寬區塊。

## 讓頁面變難看的

- 每個區塊都包成帶陰影的卡片，或卡片裡再套卡片。區塊之間靠標題和留白分開。
- 頁首用超大數字做成儀表板。計數寫進句子裡或圖例裡，圖例裡的「刪除」「新增」直接用標記本身的樣式。
- 整段的紅綠底色和段內的字一樣濃、文件內文用等寬字、說明用 12px 灰字、中文用斜體。
- 用 emoji 或 Unicode 符號充當圖示；需要圖示時，畫線寬一致的 inline SVG。
- 切換鈕用沒加樣式的原生 checkbox，或者按下去版面一跳，讀者找不到剛才那處。
- 把文件截斷成「顯示更多」；整份文件要顯示完整，只有「只看改動」打開時才收起。
