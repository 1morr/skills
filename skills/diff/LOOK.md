# 外觀

這頁是**校樣**：讀者拿它對照兩版，找出每一處改動，判斷改得對不對。內容是主角，介面退到邊上。每一頁照內容重新排版，但標記方式每頁都一樣，讀者換一頁不必重新學怎麼讀。

樣式由 `<S>/fill.py` 內嵌（`<P>/scripts/tokens.css` 和 `<S>/diff.css`）：原始頁寫結構和 JS，用下面的 class。這些不夠用時在原始頁自己的 `<style>` 補，顏色和字體照 `<P>/TOKENS.md` 取變數；變數本身不重新定義，否則 `fill.py` 拒絕產出。

## 原則

- **文件長得像文件**：文件頁的內文是書本排版（襯線字、70ch 行寬）；原文件是無襯線的（簡報、海報）和程式頁，在 `<body>` 加 `class="sans"`。
- **改動跳出來，沒改的退後**：每處改動同時有底色、刪除線或底線、頁邊的**修訂條**三種標記。區塊之間靠標題和留白分開；外框和陰影只給渲染圖和證據面板。
- **強度給最小的單位**：段內改的幾個字用 `<del>` / `<ins>`，標得最濃；整段新增或刪除放進 `.run`，淡一級，段內不再逐字標。數字、日期這類短格子整格替換，不逐字拆成碎片。
- **切換不跳位**：切換並排／合併、只看改動時，讀者正在看的那處改動停在畫面上同一個位置。切換前用目前選中的改動當錨點（不在畫面內才改找畫面上第一處），記下 `getBoundingClientRect().top`，重畫後再捲回去。
- **整份文件顯示完整**：只有「只看改動」打開時才收起沒改的段落，每處改動的前後各留一段當上下文。

## 文件頁

`<main class="wide" data-view="side">`，切到合併時把 `data-view` 改成 `merged`。PDF 抽出來的文字塊大約一行一塊，再加 `class="pdf"` 收緊段距。

| 寫法 | 用在 |
| --- | --- |
| `.toolbar`，裡面 `.seg`（`<button aria-pressed>`）、`.switch`、`.nav` | sticky 工具列：並排／合併、只看改動、上一處／下一處和「第 n / N 處」；鍵盤 `j` / `k` 自己接。工具列的高度寫進 `--bar-h` |
| `.pill` | 窄螢幕右下角的上一處／下一處，內容和 `.nav` 一樣；樣式自己切換顯示哪一個 |
| `.colhead` | 並排時兩版的標籤，貼在工具列下方 |
| `.row` | 一組改動或一段沒改的內容佔一列。並排時兩個子元素是前版、後版；沒改的只放一個子元素。有改動的列自己加一個 class 給導覽用，目前選中的加 `.cur` |
| `.chg` | 段內改寫過的段落或表格，帶灰色修訂條 |
| `.run.run-del`、`.run.run-ins` | 整段刪除、整段新增。連續的刪除段放進同一塊，新增段放進另一塊；並排時左欄放刪除、右欄放新增 |
| `.sr` | 只給讀屏器的文字：塊的開頭放「以下整段刪除」 |
| `.side-label` | 窄螢幕上下疊放時每一塊的小標籤「前 · 版本名」「後 · 版本名」 |
| `.gap`（`<button>`） | 收起的段落：「⋯ n 段沒有改動」，點了展開 |
| `.note`，裡面 `.tag`；推斷寫 `.tag.guess` | 說明，放在它那處改動的正下方（並排時自動落在後版那一欄）。「註」字由樣式加 |
| `.tablewrap` 包 `<table>` | 表格照原文件的結構畫，自己橫向捲動 |
| `td.cell-chg` | 改過的格子，右上角有三角記號 |
| `tr.row-add`、`tr.row-del`，每列最前面一格 `td.mark` | 新增列、刪除列，記號欄放 `+` / `−`；格內放原文 |
| `.col-add`、`.col-del` | `columns` 裡是 `null` 的整欄：表格上方標「新欄」或「已刪欄」。新欄只畫在後版，已刪欄只畫在前版，合併檢視兩種都畫 |

## 渲染圖對照

- 兩版用同一個方法轉圖，裁成**同一個框**：取兩版內容範圍的聯集，四周留邊，頁面下方的大片空白不要截進來。
- `.shots` 裡兩個 `<figure>` 等寬並排，`<figcaption>` 寫版本和頁碼。
- 尺寸相同就加滑桿：`.slider` 裡 `.stack` 疊兩張 `<img>`，下面 `.ends` 放「前」、`<input type="range">`、「後」；JS 把滑桿的值寫進 `.stack` 的 `--at`（例如 `40%`）。
- 兩版像素相同的頁收成一行「第 n 頁兩版像素相同」，圖放進 `<details>`。點圖用 `<dialog class="zoom">` 放大，點一下或按 Esc 關閉。

## 程式頁

寬螢幕左邊一條目錄：`<div class="layout">` 裡放 `<nav class="toc">` 和 `<main>`，用 IntersectionObserver 把目前段落的連結標成 `.here`。文字欄 70ch；要伸到整欄寬的區塊加 `.full`。

| 寫法 | 用在 |
| --- | --- |
| `.meta` | 標題下面一行：`base..head` 短 SHA（`.mono`）、分支、檔案數加 `+n −m`（`.plus` / `.minus`）、證據等級 |
| `.lede` | 摘要 |
| `<blockquote>`，裡面 `.src` | 「為什麼」引用的原文，和它的來源，例如 `5fca937 message` |
| `.tag.guess` | 推斷的句子 |
| `.tree`，新增的部分 `.new` | 呼叫樹、檔案樹這類示意圖；加 `role="img"` 和 `aria-label` |
| `.risk`、`.risk.one-way` | 合併風險的定調詞：雙向門、單向門。後面接一句理由，再列影響範圍 |
| `dl.decisions`，替代方案 `.alt` | 決定：`<dt>` 寫選擇，`<dd>` 寫理由和來源 |
| `.evidence` 裡兩個 `.panel`；`.panel-head` 的結果用 `.bad` / `.good`；輸出 `pre.out`，一行一個 `<span>`，失敗的行 `.fail`、修改後通過的同一條 `.pass`、刪減處 `.cut` | 證據：前後並排，標頭寫「修改前 · SHA」和結果（例如「12 條 FAIL · exit 1」） |
| `.hunk` 裡的 `<table>`：每列 `td.ln` 舊行號、`td.ln` 新行號、`td.sign`、程式碼；列加 `.add` / `.rm`，新檔的列再加 `.newfile`，省略處 `.skip` | 關鍵 diff，每段上方一句話說明 |
| `table.files`：`td.path`（目錄部分 `.dir`，斜線後加 `<wbr>`）、`td.stat`、`td.what` | 檔案表 |
| `ol.try`，指令放 `.cmd` | 親自試 |

圖示畫線寬一致的 inline SVG。計數寫進句子裡或圖例裡；圖例裡的「刪除」「新增」直接用 `<del>` / `<ins>`。
